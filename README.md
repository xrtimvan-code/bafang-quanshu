# 弥洛洲志

虚构历史、地理与社会制度志书。记述基准为共历742年秋，三大陆29国、271个二级行政区。

从[志纲与总目](00·志纲与总目.md)开始阅读。每卷分纵论和横论：纵论用于专题比较，横论连续介绍各国。名物与地名志解释称名传统，名称索引对照旧写。旧版题《西湾盛洲志》；现行三陆为衡岑、乌弥尔、萨阑，十二文明名沿用原设。
