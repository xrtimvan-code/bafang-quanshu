# 弥洛洲志

虚构历史、地理与社会制度志书。记述基准为共历742年秋，三大陆29国、271个二级行政区。

从[志纲与总目](1·志纲与总目/1·志纲与总目.md)开始阅读。每卷分纵论和横论：纵论用于专题比较，横论连续介绍各国。名物与地名志解释称名传统，名称索引对照旧写。旧版题《西湾盛洲志》；现行三陆为衡岑、乌弥尔、萨阑，十二文明名沿用原设。

地方传说与非自然见闻统称“幻羽”，遇见者称“临幻氏／临幻使”。可从各卷幻羽志了解记法，再到国家志读地方异事：[衡岑](2·卷一·衡岑/2.1·纵论/2.1.19·幻羽志.md) · [乌弥尔](3·卷二·乌弥尔/3.1·纵论/3.1.19·幻羽志.md) · [萨阑](4·卷三·萨阑/4.1·纵论/4.1.19·幻羽志.md)。传说与可核的编年事实分别叙述。
