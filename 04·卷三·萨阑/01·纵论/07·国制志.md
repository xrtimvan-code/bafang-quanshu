# 国制志 · 萨阑大陆

[返回志纲与总目](../../00·志纲与总目.md)

十国权力机关的形成与主要供给方式相关。高原王领协调谷粮和牧马，军镇王国核军田，法统国家分资格和选择，共和及三席制度围绕公共账与水工，诸社组织共同粮木，岸岛国家管理关货与航务。制度比较需要结合成员资格、任官办法、司法权限和执行费用，考察这些机关能够限制哪些行为。

## 一、十国中央制度

| 国家 | 最高权力与继承 | 中央官署与制约 |
|---|---|---|
| 卡尔萨恩帝国 | 伊斯卡恩家门世袭；帝位须冠誓合会确认成年候选人的誓约，废黜须五个历史领系的共同代表与祭团共同提出 | 冠约政院统粮税、驿务、军籍、工渠；诸领议会认可特别征役；巡察使不能自带军改判 |
| 赫达兰王国 | 赫达尔王族世袭，未成年由三镇摄理与王母共同监护 | 王议院与镇议会协定军粮；驿务署、水田署、库署、巡判院分别记账；镇将不得兼本镇终审 |
| 毗萨罗法统国 | 王族与法学家门提出候选人，释义资格院审查，国议会从合格者中选终身执政 | 执政署统六院：田水、财赋、吏选、道路、外约、审判；释义资格院审资格与条文一致性，不代替审判院调查案件 |
| 萨伦南王国 | 摩迦拉王族世袭，学堂只见证就位，不授予王位 | 王务院、田水局、海贸局、王库、巡审院；十二学堂咨询会可提出书面异议，王须答复但一般无需接受 |
| 埃沃拉共和国 | 公民议院与工坊议院共选三名执政，任三年，可连任一次 | 公账局、渠工局、物验局、常任吏务局；高审庭对行政违法受理诉讼；执政不得兼经营公共采购商号 |
| 德维恩三席国 | 城镇、乡区、公共工坊各按自身章程推举一席，任四年，不立即连任 | 三席合议书局、共库、水约署、巡裁署；两席可决日常，战争和长期特别税须三席一致；不得以多数剥夺某席推举权 |
| 奈洛王国 | 温索家门世袭，渠会与林约会共同承认税水誓约 | 王田署、林约署、仓赈署、巡判署；重大林地转让须涉事林社认可，王庭不享无条件处分权 |
| 榕约诸社 | 无全国世袭王位，五个创约共同体由现辖各区共同推代表组成共约会，召集人任两年 | 护路组、共粮仓、共约审判会、林水约记所；代表可被原社撤回，日常多数，新共税须五个创约共同体一致；全国权力依共同约和代表程序运转 |
| 曜津王国 | 邵氏世袭王位，港城会议确认关税、债务与征船章程 | 王务院、总关署、海务府、田渠署、王国法院、礼院；税务监察与船舶征用分别签批 |
| 索汐王国 | 温那尔家门世袭，帆会确认成年继承人；危机时可要求王族重新提名 | 王航帆院、海约复核庭、候航灯署、库署；港镇会议可否决特别船税，但不能单港擅停共同救援 |

**冠约政院的名源。**冠约指帝号之下诸领承担粮税、驿务与军籍的共同约束，政院办理这些日常政务。旧称帝务院较重帝廷一方，现名同时提示其须按约登记；特别征役仍交诸领议会认可，政院不因此成为各领土地的所有者。

**冠誓合会的名源。**冠誓是成年帝位候选人接受的誓约，合会指五个历史领系与祭团参加的共同确认。旧称冠会为省称；它处理帝位承认，与日常议役的诸领议会分工，不能凭冠字将祭团写成唯一的选君者。

**诸领议会的名源。**诸领说明代表来自历史领系，议会以特别征役审议为主要职能。旧本省称领会，在此确指机关；普通语言中的领会仍是理解之意，不能当作机关全称替换。议会与冠誓合会有关联，职责并不相同。

**释义资格院的名源。**释义指对条文的解释，资格指执政候选人与法学任职所需的条件。旧称法统院容易被误读为包办一切司法的机构；现名突出资格及条文一致性审查，调查案件和作实体裁判仍由审判机关承担。

**王航帆院的名源。**王航帆院承旧称王帆院，航与帆共同指向王国船务、护航和港约责任。它是索汐中央机关，并非帆会全部船户的家产；救船专款、海约复核与候航事务仍有各自签验程序，不能由院名推出统一包管。

**海约复核庭的名源。**海约涵盖航运、救援与货权等约定，复核表明跨港及重大争议可以由此审查。海约庭是旧省称，现名不表示一切案件均从复核庭起诉；地方港庭先受理的范围与上行程序仍依具体案件区分。

**候航灯署的名源。**候航指观察并公布地方风潮条件，灯署保留灯航设施及相关登记的机构称谓。旧称灯航署将灯列在前，二者指同一机关；候字不保证每次航期无误，署名也不使其取得王位确认或无限收费的权力。

**三席合议书局的名源。**三席说明决定来自城镇、乡区和公共工坊各自推举的三席，合议书局负责共同议定事项的文书。旧称合议书局可作省写；书局不是城席的下属，也不能把三种推举资格合成按人口平均的一套选举。

**林水约记所的名源。**林水指诸社林地与用水关系，约记指保存共同承诺及使用记录。旧称木水记所较贴近具体材料，现名概括其事务；记录提供核对依据，并不让保管者或其家门拥有所记林泉，争议仍依约判程序处理。

**共约审判会的名源。**共约是诸社确认共同责任的约，审判会依其受理共同财产和重大复核等争议。旧称约判会为短写；它与推举代表、审预算的共约会不是同一机关，也不能将作为约本文献的《榕约共木本》写成主持复核的人。

## 二、官员怎样产生

卡尔萨恩地方领长分帝任和旧领家门推荐两种，冠约政院设三年审账，任期更替依另定任命程序。赫达兰镇将常出将门，文书与巡判按经历荐举。毗萨罗以考试、书判实习和同僚审资格结合；考试偏官文，译口口语居民常依赖代书。萨伦南另有贫生名额，由乡仓供食，却会被地主借户名占用。

埃沃拉常任官须通过计量、账法与渠工实作；公职不随执政更换，但严重失账可免职。德维恩的专业官由三席共同选任，不分别成为一席的私人官队。榕约记录员常从轮值书屋训练，不必具社老家世；小社无力长期供书吏，必须向联区借人，造成实际发言不平等。曜津保留承曜吏科式考核，却取消按父官确定应试等级的旧例。

各国公民和成员资格的开放程度随机构与事务范围而异。埃沃拉公民议院要求成年、常住、纳公税或具认可工坊资格，贫民与多数未登记妇女无席；榕约成员会议允许成年女性和婚入者，但外来季工未承担完整社役时没有完整表决权。德维恩公共工坊席有妇女代表，城席的财产门槛更高；一国之内已有不一致。

## 三、司法与具体条文

这里列出的条文是现行法规的代表条款，编号取自各国常用汇编，不宣称一条代表所有案件。严重犯罪均不得由宗教领或私人家门私下终结。

| 国家 | 代表条文与制度 |
|---|---|
| 卡尔萨恩 | 《驿草田约》27条：未给草料凭券不得要求户主自行补马；《冠约领律》61条：领长不得把灾年免役折为同额私债 |
| 赫达兰 | 《镇仓交粮令》18条：守镇粮额须注明来源与交期；《上下渠约》33条：上游军田新渠须有下游验水，不得以军令省略 |
| 毗萨罗 | 《答义释例》债章12条：译本契意相异，先查当事签认语言；诉讼章44条：资格审查不得代替案证调查 |
| 萨伦南 | 《学粮田律》9条：贫生田不得售给主持学堂家门；《巡仓审令》22条：王仓赈粮借领不得以人身作抵押 |
| 埃沃拉 | 《公簿交账约》31条：采购议员须报间接商号利益；《伤俸共责约》16条：共责工伤应以持续供养为主，不得只付祭费 |
| 德维恩 | 《城乡工合席约》7条：水闸归水约署共同管；《公坊共工令》26条：伤俸在工坊解散时列优先债 |
| 奈洛 | 《林水渠约》41条：婚入者原社使用权不得当然没收；《王仓赈令》19条：赈粮户名可由成年实际照料者登记 |
| 榕约 | 《榕约共木本》13条：林社共木不得以一家债约抵押；《共路守约章》21条：撤回代表不免该社已经确认的公役 |
| 曜津 | 《港货验关令》56条：货名不得因进口地而重复征同项验费；《适航征船约》24条：不适航船不得以战时名义强征 |
| 索汐 | 《帆户救航约》38条：救人义务先于货物索偿；《岛灯冬粮令》11条：远岛冬粮不得由祭灯人私贷收息 |

程序通常是乡区调解、二级法院或约判、中央复核。抄契、证人、验物与官账比单一口供可靠，但酷刑仍未完全废止：卡尔萨恩对严重通敌采用限定刑讯，毗萨罗答义释例派要求证据先行，古典守序派保留某些程序。规范与实际执行之间的差异须由具体案件核查。

## 四、制度怎样在实际事务中运转

卡尔萨恩的冠誓合会每三年召集一次，普通税与王位确认分别开簿，两类许可分别登记并依程序确认。冠约政院在728冻灾后开设冬仓巡验，领长常试图把优先给本领军队的粮记作全民救济。赫达兰镇议会则以军粮交足作为同意新工事的条件，赫达尔王廷若借商业收入越过镇会，必须说明其是否准备把临时收入转成永久兵额。

毗萨罗释义资格院有24名终身资格委员，但重罪、失去任职能力或重大隐利可经国议审理免任。国议会有谷地、城镇、学堂三类席位，普通农户多由地区代表间接表达，采用地区间接代表程序。萨伦南十二学堂咨询席按教学持续与贫生供食确定，王庭不得仅以赞歌好坏增减席位；它们能公开异议，却没有全国预算否决权。

埃沃拉两院各60席，公民议院按地区选，工坊议院按认可行业并留乡工席。全国公民登记约占成年居民三成，成人多数并无票；执政不得用“不在册”拒绝受理刑民诉讼。德维恩三席各有七名辅助议员，城席按镇议推举，乡席按灌区户会，工席按公共坊工。三种制度的门槛不一致，三席按组织资格形成，所代表人口和表决门槛各异。

奈洛渠会审年度维护，林约会审新林地转让，两者成员有重叠，但须分别授权。温索王族控制王仓，可以在短期灾年先放粮，后向两会报账；紧急放粮仍负事后报账责任。榕约五个创约共同体各派四名代表，共约会共20人，日常多数须至少三个创约共同体代表赞成，防止大区人数虽相等却通过长期代理控制小区。召集人管理议程，不拥有单独发军令的权利。

曜津港城会议共40席，曜津京府最多、井塔岛最少，港口纳税额影响席数，远岛井工因此诉求提高救援事务票重。邵王廷愿在救船专款中设居民代表，却反对重划海关席。索汐帆会由港镇代表、登记船户和远岛代表构成，救船基金的支出要三类分别签认；王帆军预算中的代表票重存在差异。海洋传统既能跨港团结，也能让拥有大船者占有更多发言。

## 五、诉讼的具体路径、证据与案件费用

一般案件先由地方接诉，再按管辖、性质与复核条件逐级处理。原告提出自己所用语言的事实，代书注明转写人，官署先确认管辖及是否涉及宗教领免额。乡调解可解决小额货费，伤害、强迫债役、重大地权与官吏滥权须正式受理。二级裁判按国家制度复核，中央只接重大错误、跨区冲突或具有代表性的解释问题；不存在所有案件人人免费往都城再审的保障。

676年萨文桥译约案的诉人先在桥口找县正，县正认为异国货主应交王库商道官，商道官则认为车损在本县发生。两次推诿使车夫多付宿费。巡判院后来指定发生地受理并请对方关署验契，先确定程序权限，再调查契意与责任。当事人在等待中卖掉一部分备粮，判费分担后没有完全取回损失。有利判决之后，等候、失工与变卖粮食造成的经济损失仍可能留存。

证据分契本、官账、实物、现场痕迹与证言。隐利采购案的正式官账可能掩盖关系，病舍护工的口述则可帮助核定事故当天的在场者，二者均须与其他证据对照。法院要求查看证人是否同债、同家、同雇，但具有关系不代表必然说假话。女工在联堰工伤案中被旧判官当作家属弱证，后来以轮值表和工具修理日期增强证言。

小案诉费常相当普通粗工两至五日工资；跨区要另付路食、抄卷与证人误工，可能达十几日甚至数月所得。毗萨罗有贫诉免抄额，判断贫困需乡仓证明，外来人较难取得；埃沃拉由行会互助仓提供部分费用，无行会的季工则依赖雇主保证。德维恩长俸所为已验伤者统一追债，减少个别户诉费，也使尚未被验为工伤者被留在门外。

**长俸所的名源。**“伤俸所”为旧抄本和地方口述并用的名称，现整理为“长俸所”。专名记录本地语言、生产或共同责任的记忆，通名仍按原文对象解释。名称的定写不改变人物生卒、事发生年、成员资格及官署权限；旧写留在引文与异本说明中，不能凭改名推定另有实体。

刑事案件中应区分拘押、询问、裁判和刑罚执行。十国未建立现代专业警察体系，由城卫、乡约、官差与王军分担治安，军官因此有机会扩大“军务”范围。榕约约判可罚役与限期离社，无法将人秘密终身囚于祭林；曜津法院对船上重罪有权拘人，但外交船员案件需迭嶂使署协商。史书赞扬治安时，应问秩序是否建立在可申诉的约束上。

## 六、两场没有简单好坏结局的改革

649年埃沃拉工徒期限改革限制师徒身契最长七年，并禁止把孩子欠父亲的债写入学徒契。工主哈森·恩丹反对，称训练成本无保障；熟工互助代表利萨·塔依则说七年已覆盖技术训练。这里的恩丹与塔依是649年的改革当事人，不能与742年同名坊户或现任者合并。新法让一批学徒按期出师，部分工主却改收高额入坊费，使穷户孩子更难入学。公坊随后设担保额，公共财政开始承担教育成本。取消人身限制是实质改变，却没有消除财产门槛。

711年萨伦南债役期限改革将一般私人债役封顶五年，已还价值超过本息者可诉终止。田主以食宿也是支出为由扩大成本，欠役者以免费田工已经抵债为由申诉。巡审院要求另记工资与食宿，不得把零工资劳动再算作未偿；无账户需要证人估工，仍不容易。改革并未宣布所有债都无效，而是使不自由劳动不能无限通过记账延长。其执行体现为一案案核数，没有一个单日从此人人自由的时刻。

现行111区分别设置户籍、税役、治安与地方司法机关。旧区系是共同推举和权利承续的历史共同体，同系新区共同推举原定代表，不另设上级行政官署。卡尔萨恩冠誓合会的五领系份额、埃沃拉两院各60席、德维恩城乡工三席、榕约共约会二十名代表和曜津四十港会议席均维持既定程序。新区数量与中央议席不作等额对应。

## 七、归纳与评价

十种制度都试图使军粮、水土、解释权与居民义务相称。制约机关是否有效，取决于其账源、成员资格、撤换能力和受理案件的费用，这些条件决定其实际制约能力。
