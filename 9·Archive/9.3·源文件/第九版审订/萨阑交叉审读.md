# 萨阑第九版新史交叉审读

只读审查；未修改书稿。审查范围为卷三纵论03文明志、05历史志、06王统与编年志，横论00萨阑志及01—10国志新增“古代前史”全文；结合卡尔萨恩国志旧历史段、前九世纪长编开头与历史志“古帝国的疆域与统治层级”段，核对新旧衔接。没有通读十国全部后期长编，不覆盖根代理正在修改的其他纵论。

## 应修的明确表述问题

### 1. 石渠首句范围和同段后文、各表不一致

文件：`04·卷三·萨阑/01·纵论/05·历史志.md:17`

原句：“前2100—前1800年的石渠祭仓邦控制冠山若干泉口。”

同段却继续写“约前1770以后”由同一仓主机关催粮、扣役人，至“约前1690—前1650”焚仓；国志01第23行明确采用“前2100—前1650的石渠祭仓邦”，06编年31行亦以2100—1650概括。这不是无关的遗址范围问题：历史首句把政体控制期截止在1800，后文仍在叙其统治。

最小建议：改为“石渠祭仓邦约前2100年形成，前1800年前后仍控制冠山若干泉口。”或将首句改为“约前2100—前1650年，石渠祭仓邦先后控制冠山若干泉口。”后者与现表统一，前者更保留从兴盛到衰亡的阶段区别。

### 2. 大渠庭终结事件缺少1060到1020的阶段连接

文件：`04·卷三·萨阑/01·纵论/05·历史志.md:33`

同段先写“东谷大渠庭约前1250—前1020统合主渠粮役”，再写“约前1060的连荒使大仓被夺，逃出的抄者携短契到不同谷舍，主渠再无共同征役。”

文明志03第14行、王统志06第33行、毗萨罗国志03第17行均采用前1020为终点；毗萨罗第19行也将夺仓放在约前1060连荒后。目前句子直接把共同征役的终结接在1060事件后，与“统合主渠粮役至1020”的功能界定不清，读者会得到两个终点。

最小建议：保留两节点，将历史该句写为“约前1060起的连荒使大仓遭夺，抄者陆续携短契转入各谷；至约前1020，残余主渠征役也不再统一。”这样只是明确现有两个日期的过程关系，不增设政权或事件。如作者本意是1060即全部终结，则需统一另外三处1020，修改面更大。

|---|---|
| 炉湾铜料邑 | 历史、文明、埃沃拉新前史均1950—1660；德维恩将迁出者放在前二千纪后半，承接顺序可通。总志2100—1650为合述石渠与炉湾的总范围，未理解为炉湾单独起年。 |
| 赫达河阶军盟 | 历史1470—1280，约1320远征失败；赫达兰国志形成、败征、失共同军仓顺序相合。 |
| 三湾桨盟 | 历史、文明、总志、曜津均1390—1170；约1230夺岛败征与索汐受损、迁湾、失换粮对象一致；未被当成邵家或里莎的连续王统。 |
| 阿瑟旧冠国 | 1180—970宽期与980—940逐渐失共认可以并存，970处于衰亡范围中；各国志明确区分前九世纪重建仓邑、前六世纪领王与古旧冠。 |
| 连湖仓盟 | 历史1160—930，奈洛及榕约新前史同；热病、洪水损粮后加征、林社拒木、分散高仓相互支持，没有把奈洛/榕约当作古国预定分界。 |
| 转运堰王 | 历史1120—990、王统表及德维恩新前史相符；521三席没有提前投回旧堰王。 |
| 前900旧起源 | 03文明、05历史、00总志已把900以后写成重建；卡尔萨恩旧早史段及长编前九世纪开头也已承认更早祭仓/旧冠覆亡，未发现仍称900为全大陆最初起源的硬残句。 |
| 前216冠号与前132南征 | 历史、卡尔萨恩国志、王统表相合；纳洛在位149—116、132南征、116亡均相容，没有用勒萨恩本人覆盖曾孙事件。 |
| 154—188空冠 | 历史第177行、总志50行、卡尔萨恩27行、王统13/42/58行相合。地方守仓及冠泉仪式仍存，不构成全国共冠连续。 |
| 188帕洛、263失仓、274复名 | 各处都是帕洛异家取得部分领会拥立，263失主要关仓，274复用伊斯卡恩冠名；均否认仅凭婚入复号证明父系连续。未发现把帕洛写成伊斯卡恩本家支房。 |

263—274没有另编国君表，但本文均只声明263失去主要关仓，并没有说该日最后一名帕洛必然死亡；274另起冠廷，两者不构成已证硬矛盾。本次不建议凭空补出十一年的新统治者。

## 不应当作错误处理

“前1200—前900”章节中回述前1250大渠庭，是分期叙事带入先行阶段；王统表已经用1250—900汇总，不必为了整齐机械改动全部起年。古政权名已解释为遗址/残契后世合称，没有需要新创古族名来填补的空缺。

未核实任何后期人物完整寿命分布、军备采用史、现行政区数据合计；不以本报告替代这些专题审计。
