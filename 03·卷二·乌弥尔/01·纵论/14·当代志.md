# 当代志 · 乌弥尔大陆

> 《弥洛洲志》卷二。记述时点：共历742年秋。

[返回志纲与总目](../../00·志纲与总目.md)

## 一、共历742年秋的共同局势

大陆没有全面战争，北井原旱后债、两门风灾后船贷、南部共有闸费用是主要压力。粮食在产区并非全部绝收，但运输损耗、贷款到期和役期安排，使城市与末渠户承担不同的短缺。承曜旧正统仍用于仪式和外交争辩，各继承国已建立自己的官署，不存在一个仍能调度全部两岸的隐形中央。

## 二、十二国的主要政策争议

| 国家、最高执政者 | 主要问题 | 参与者与眼前可能变化 |
|---|---|---|
| 库尔班 阿苏特·胡尼 | 旱后收籍、粮贷与骑役 | 汗册整籍派、黛骝旧旗领和小牧户争登记权；742年仍行单一主役籍，不把未来修改写成已实施 |
| 承渠 阿苏特·依乐 | 末渠减役与旧闸债 | 受水分债派提依实际得水收渠费，上渠原额派怕偿债不足，佃户要求先减重复工役 |
| 鄂勒温 赛仁·额芙 | 开放冬营与盟费 | 季草会商派愿救灾收临时费，小牧户怕本地草被挤，大群派希望按畜数获得更多话语 |
| 洛珩 兰珊·娅薇 | 鱼米折租是否改钱 | 廷税折钱派、富大网户、贫渔户、粮商四方分歧，王弟若薇支持保部分实物折租 |
| 苏迈 首轮值依薇·娜洛 | 采购公开与乡席扩增 | 公簿披账派和乡席派部分合作，师傅旧席派怕议席被削；提高透明不等于全国普选 |
| 凯兰 韦沙·爱伦 | 乡审日、庄役与港费 | 侯契守持派保市特许，地产房抵制巡判入庄，田约和议派推动固定听诉日 |
| 渊流 绍朗泉 | 四闸费用与上游测流 | 诸渠平款派拟公开每日水尺，楗上定额派要求旱年先保本地田，小畴户派反对富田优先 |
| 众契 壬霜序 | 外雇纳社与妇户资格 | 更契派、妇户派、古约派交叉组合，桑垄已变、石槽多数社尚未同制 |
| 苇章 翟洪恭 | 学田审计与实务选官 | 学产公资派想保财政稳定，契经师派怕王廷干预讲学，尺验实学派促农医水算列入高阶考试 |
| 曜廷 晏昭辉 | 旧廷礼费与军税期满 | 王约补制派支持预算审核，序仪学派保大礼，瞻水城田户要求临时军税按期停止 |
| 西承 首席棠与衡 | 风灾公债和省份分款 | 合债核簿派欲延债，货关派怕信用下降，省税自理派拒联署直入地税 |
| 北候 奈赫·瑟娅 | 公共舰债与份船役 | 合舰分费派主按资本份额出款，私航自费派只愿按实际护航次数付，网份渔户派要求海救优先于商船护航 |

官署的具体人名见国制、方域和军政志。临时政策是当下事实，改革建议只记为方案，不预告一个必然成功的未来。

## 三、跨国关系的四条线

库尔班与承渠互通盐粮，汗庭不能凭阿苏特同宗控制渠费；库尔班与鄂勒温有边界巡查，也有共同救草。洛珩与苏迈沿旧槽保界、按新槽航税，641年异槽疏河约仍有效，不能因两地有争吵便称它们战争不断。

渊流、众契与苇章共同使用渊流水系，四闸约只由前两国签，苇章通过下游检流附约参与，保本国地税与行政权。曜廷与西承虽互争承曜解释权，南障界仓与故廪共同查粮是现实合作；贸易所需的银衡和契译压过不少礼仪争论。

北候与萨阑索汐竞争份船承统、护航费与灯师资格，同时共用救船互认簿。来自曜津的银市章程影响合津，经承税联省院审议修订后，在本地法律下施行；萨阑化玻工匠在苏迈推广耐热窑，仍需当地陶土、燃料与学徒适应。详情到第三卷按来源地区展开。

## 四、公共消息传播与政策判断

官报在曜京、章台城、合津发行，港市有抄报、讲读和私刻单页。偏远牧旗主要听驿人、商队与祭会；同一开闸令在会槽两日可知、下尾圩可能十日才译到。没有迅速均等传播的舆论场。733年所谓“众契要夺石楗堰”的传单把共测流误写成共管上游地税，曾导致粮船被拦；双方公译吏公布约文，仍花一个汛期才恢复信任。

公簿披账派并非全都赞成减少军费，序仪学派也不全拒绝账核。家门、母语、行业和政策取向相互交叉。若一位巴克泉守赞成公爵，却在减役上支持佃户，体现其在公国权威与减役事务上的不同利益位置。

## 五、政策现状与提案的区分

742秋现有风险包括北井原债务性迁徙、承渠上游拒额、苏迈资格冲突与北候公共舰款拖欠。它们可以缓和也可以恶化；本书没有把743年任期改选、战争或政变作为已发生的事件。收成、婚产、船修与学徒生活与国家政策同时展开，地方经济和家庭安排构成当代社会的重要部分。

## 六、归纳评价

742年秋的主要政策压力来自北井原旱后债、末渠费用、公共船债与代表资格。家门、母语和行业联盟在不同税役问题中重新组合，既有制度约束与新方案同时存在。粮价、工期、居留和灾后恢复构成地方社会的持续议题，正式表决及实际拨款决定政策何时转为实施。
