## 一、名称怎样留下不同年代

乌弥尔地名不是一套同时订出的官名。井边营地、湖口泊船处、渠头工棚和海崖炬台，往往先有行路者口头称呼，后来才进入户籍、税册与官印。一处地方可以在粮券上用短名，在祭歌中保长音，在地契上另附水口或田垄。通用书面语把这些名称放在同一页，并不说明居民原先都说同一种语言。

辨名须先辨所指。赫恩既见于湖名，也见于都城名；会槽既是汇渠节点，又是驻署城市；库尔营是冬营共同体，额尔帐则是它的治所。相同词根说明取名关系，不足以证明两者范围相等。一个城的街市扩大以后，原来井、渡或岗的名字可以继续使用；一个王家绝嗣，沿坡垣形成的国名也可能不变。

旧写仍有史料价值。军粮券、鱼租册、工料札和航图所用字不完全相同，可能反映口音、识字习惯或记账目的，不能一概判作错字。反过来，后抄谱书把熟悉的今名写回远祖时代，也不证明今名当时已经通行。以下称“旧写”，说的是有具体材料层次的名称，不是把现行名号归于742年同一场改名。

## 二、十二国各有自己的取名路

库尔班的库尔是瓜凉北原支有围井的营地，班保数营共轮草的尾音。谷仓抄吏曾借谷陵之义写瓜陵，486年盟册则采用营旗自称。这里的汗国是后置政体称，早期营约不因后来的国名便自动变成汗廷下属。额尔帐另取谷盐语两条营路平衡交会之义，旧粮吏以衡译之；不能用库尔班的词源代替这座城的帐名。

承渠取旧朝承领工籍的承字，渠指整个灌网。159年总闸迁村后的工料札与公廷官书保存不同称法，472年独立约接续水额与债账，国名由工程地称进入政治文书。鄂勒温则保西旗泉路语“临泉暂止的营约”之音；603年自由营约、606年冬草约采用这套自称，东旗抄本常记阿勒温。自由旗盟说明免旧贡的关系，不表示每一位寄居者都取得盟票。

洛珩的较早湖口音洛哈恩指连堤内水面，王廷曾省写芦桓；294年新王系取湖名短读，没有以兰珊家姓替代国名。苏迈来自下河语苏梅伊的共卸货岸，湖廷货札写索弥，港工省音说苏迈。418年公簿采用本港读音，但城乡资格仍由章程分列。凯兰来自坡垣旧音卡雷恩，驮商与湖廷各保凯兰、卡雷两种短读；361年依婚产契继侯，家门换了，坡垣国名仍续。

渊流的渊指旧渠语深槽，流指行水，抄契人早写元流。497年五渠重组，合渠国保水网地称而不保旧联庭的单家共主；大元溪文明的名称另作文化传统，不与国号合并。众契取南桑契版“众户互保”的用语。509年原有八十六份城乡契约，后来的赞歌用百作成数，才有百契之称；今国名没有把创约实数改成一百。

苇章的苇承荻田旧称，章指田契分条。562年王约把官学与田户辖地结合，官书写荻文以突出文教，乡契仍记苇田；国名保两层来历。曜廷的曜出承曜礼书，廷为465年王约保留的西廷官署，旧称景廷曾把王族姓与署名连写。晏氏是王家，曜廷是国家，两者不能互代。

西承的承来自西岸承税簿，西记两岸历史税区的位置；451年外债互保、468年联省形成以后，这个账名才扩为国家合称，旧官书也曾写西宸。北候取七斗航语北岸候汛，灯簿写候，后抄航书配文明名而写北斗。531年海盟以护航约联合港岛，候不是新的文明称，召集人也不是拥有诸岛的海王。

## 三、行政通名与自然通名

旗源于井修、冬草与军役的共同体，营是实际驻帐地；同根旗名与营名可以对应，却不总有永久城墙。镇领多由仓市受诉和税籍办理形成，领还可能承地产或巡牧来历。芦赫的库原是收谷泊舟处，温洛库、帕伊库保留这个旧通名；它们后来有市场和地方辖权，库不能只按现代仓房理解。

渠区、渠领与圩领同属二级，名称分别突出受水段、登记范围和堤内治理。社联来自共同代表约，成员公社另有基层社籍；某些二级地方全名也沿用公社一词，须看图码、官署和所属契约辨层。港盟、岛盟、岸盟各由不同港岸共同体形成，长汛岸盟是大陆岸带，不能因海盟多岛就改写成孤岛。

河、湖、岭、脊、淖、沚、汀另属自然地名词层。淖着重浅水湖，沚着重水中小洲，汀着重临水浅地；木楗是闸件，堰是工程，二者又可能转入聚落名。石楗堰从石基木楗得名，蒲沚镇从蒲草小沚得名，素冈镇从浅色土冈得名。名字可以保存旧环境：洲连上岸仍叫沚，作坊改业仍叫桨坊，这类化石称不能直接当作742年实地状况。

槐脊曾写槐梁，旧驿图重横过山梁，炭工路册重沿长脊采薪。哈岚旧音指暗色岩脊，粮吏意译黑岚。洛恩是可通载谷舟的下河词，旧译借芦字说明苇岸；河名随新旧槽并用，635年改槽没有自动移转641年约仍认可的陆界。

## 四、姓名、家门与个人简称

瓜凉营札、芦赫名谱和七斗航籍多把家门名与个人名分记，通用译文以间点连接。阿苏特·胡尼的阿苏特为家门，胡尼为个人；阿苏特汗家与承渠公家同源，不给任何一方另一国的税权。阿苏特、苏勒沁、塔拉沁等姓称保本地长短音，旧官簿有省尾写法；其更早词义有些已经无法确知，不宜凭今字凑出一个共同祖神。

阎、郝等单字姓与早期双语登籍有关，绍、江、佼等家门又见于渠乡田契、学籍和作坊机份。旧契的颜、贺、邵、蒋、乔字形与今名谱并存，不能把字形更换说成742年各家共同受封。晏氏旧廷谱与审氏经师学舍各有传承，棠家银市同样需要区分商产和官位；一个人姓什么，不决定他能审谁的案件。

简称必须跟着本人走。兰珊·罗因与兰珊·若因是两位不同前王，奈赫·瑟娅与兰珊·协娅也不因近音合为一人。称胡尼、额文、若薇时，须据该章的家门、亲属与年代确认，不能把一个王弟的简称转给另一位先王。收养尤其提醒姓名与血缘分别登记：艾珊家有灯师和领航家，奈赫份船房能收亡船伙伴之子，同一家门内还可能有不同母语。

## 五、礼名、派名与书名

绳穹道以绳结见证井约，以穹指不画形像的天，长穹是东部抄吏省去仪物的旧译。洛母祀的洛来自湖口泊水之称，芦母旧写借草字解释音；淖母、津母、畴母分别重湖、渡和田，不是三位各自建立神权国的神。水序教的序首先是取水轮次，旧称轮水突出轮像。638年迁祭轮协议留下经师、信众和水工三方说法，后来的礼名不能把实际协商写成一位祭师的命令。

序光礼的序兼记官祭阶等与亡者唱名，官廷九阶灯列和乡社齐灯因此既相连又相争。候星灯约承七段航候点灯的传统，古词称七候灯；亡船名录、救助誓言和艇费进入契券以后，灯约之称更常用。七斗七段航季没有因礼名采用候字便变成等长月份，仪物七灯和具体港社名也应分别读。

汗册整籍派、尾渠足水派、女户独籍派以当时主张为专名，派为松散取向通名。它们见于提案赞同簿和后来的争论文字，不一定有不变成员册。公渠先役派与守契派争工程、役期和迁置程序；宗田原额派与王学公资派争学校田产。不能因为某人属一派，就把该派主张写成已经实施的国家法律。

书名还保留传播路线。《异槽舟记》取新旧河槽及舟户题材，651年路赫·依汶初编后的王廷本、港工本各改收尾；题同不等于立场同。《下尾役七问》原由松阿循口述、韫小渠记成，简称《役七问》使不识字者也能背诉求，却不能单凭韵句替代判牍。《候归帆札》在灯会常选读亲属信，原札仍多算水、绳和合伙债。《畴尺图录》则把农时、尺和田具同页刻出，727年原版与734年补刻页须分别校读。约集、判簿和祭词的题名由使用者形成，未必出自一次统一颁布。

## 主要人物姓名选释

本节选取现任国家主要负责人、开国者及贯穿重要争议的人物。旧稿姓名与现行姓名的对应属于本书译写修订；下面另释世界观内的家号、个人名或后世称号。普通名录人物只保留统一译写，不逐人编造改名故事。

| 人物 | 称名及其来历 |
|---|---|
| 阿苏特·胡尼 | 阿苏特是汗家与承渠公家共享的谱号，其早义已不完全可释；胡尼来自瓜凉北原语“耐住冬夜”的祝名。两支同姓只证明谱系承接，不代表胡尼的汗权覆盖承渠。 |
| 阿苏特·依乐 | 依乐取南原旧语“水来可歇”的短音，公家定居渠乡后仍保此人名式。汉字乐只是记音，不宜读作其政策必然宽缓；依乐与胡尼的个人名也不按统一辈字排列。 |
| 赛仁·额芙 | 赛仁是会商担保家门的旧号；额芙意为“先到泉边者”，原是季营中男女都可使用的祝名。取得盟首职位须经推举，个人名不构成井泉优先权。 |
| 兰珊·娅薇 | 兰珊承王家沿用的湖口长音，娅薇取芦赫语“初生苇芽”的人名。王弟若薇的近音反映同室祝名的习惯；二人仍是不同人物，不与旧王罗薇合并。 |
| 依薇·娜洛 | 依薇源于港市寄券房的旧称，后来固定为家名；娜洛在下河语中指“照看归舟”，是个人祝名。旁房与富房可同用依薇，家名不说明其资产相等。 |
| 韦沙·爱伦 | 韦沙是旧侯家的谱号，早义有异说；爱伦保存坡地语“暖季新叶”的祝名。其家承侯以前已有此命名习惯，不能把爱伦解释为本次继承所新授的爵号。 |
| 绍朗泉 | 绍姓为旧双语登籍定字，朗泉是渠乡家学常用的文辞名，取明达、源流不竭之愿。水官家子弟以水取名并不少见，但不因此取得世袭水职。 |
| 壬霜序 | 壬是家谱姓，霜序取霜降后整理农事的季节意象。它不是生于某一确定霜日的证据，也没有预先含入他后来提出的更契政纲。 |
| 翟洪恭 | 翟为王家姓，洪恭沿用旧学中的宽厚、敬慎二义。王廷教育采用此类训辞名，乡里仍有草木名与短名；不能把一国居民都按王室辈字命名。 |
| 晏昭辉 | 晏为旧朝宗支谱姓，昭辉是家中采用的光明祝辞，与承曜礼书的光意象相通。个人名对旧礼的借用不等于仍拥有跨海帝权，今王权限来自新王约。 |
| 棠与衡 | 棠为贸易家门姓，与衡是父母所取的文辞名，取相与持平之愿。衡既可用于量器，也可用于一般公平观念；不能因他后来管理公债，就把名字写成受职后所赐。 |
| 奈赫·瑟娅 | 奈赫承份船家号，瑟娅是航语“得见岸灯”的祝名。收养可以带来家号承接，召集人职位则另经盟会推举；同名船房成员并非都与她有血缘关系。 |
| 苏勒沁·额黛 | 苏勒沁出自军旗驮马家门，额黛保北原语“赤晨”的人名根。它与黛骝旗的今名近音，旗名却不能反推为额黛的私人营号。 |
| 江识穗 | 江是渠乡登籍姓，识穗是把读书与粮作并举的家中愿辞。名字不授经师资格；其均水主张须由田契、师承与实际提案解释。 |
| 艾珊·穆依 | 艾珊是容纳收养与师承支房的灯师家号；穆依取“守夜不寐”的旧航语祝辞。灯祭职权来自学习和社议认可，并非有此名的人自然可以主祭。 |

## 六、检索选例与归纳

名称能把地形、语言、劳作和政治记忆留在一处，但也会省略不利的往事。读者应将今名、旧写、材料年代及所指范围合看：地图辨所在地，契书辨财产和权利，年表辨人物与事件，名谱辨家门和个人。这样的合读既容许同地异名，也避免把近音当同人、把地称当主权、把后来官名当成早期生活的起点。
