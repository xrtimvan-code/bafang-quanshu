## 一、家门资源与政治延续

家门通过土地、学校、份船、婚姻和担保延续影响。一个姓氏可能有支持不同政策的支房；一个人依靠家门起步，也可能在任官后与本家发生冲突。以下是重要家门，按主要资产与政治影响选取的代表名录。贵族职务、资产和国家官位必须分开说明。

| 家门 | 行业与核心资产 | 主要人物及内部关系 |
|---|---|---|
| 阿苏特 | 库尔班汗家及承渠公家，分支始于承曜赐封 | 胡尼主张收籍，承渠依乐主张协商；共同祖系不给汗管辖公国的权利 |
| 苏勒沁 | 黛骝军旗、驮马与冬草圩 | 额黛保护旗权，弟额文投资麓泉粮仓，担心旗战破坏商路 |
| 阎 | 麓泉文官、粮贷与翻译学校 | 中靖重仓政，如泉管理市镇，阎如泉的妻郝碧穗经营独立货栈，不全归阎家 |
| 塔拉沁 | 鄂勒温牧军与泉井护卫 | 胡娅支持小牧户，叔父额坤拥有大群，两房在轮牧表决分立 |
| 兰珊 | 洛珩王室、王田和湖堤礼权 | 娅薇整税，王弟若薇主张保留鱼租；二人争论未构成已发生的叛乱 |
| 法伦 | 芦赫粮田、王廷文官与织造投资 | 缇娅任赫恩都守，因薇与师傅行会结盟，旁支玛伦主张女师傅完整全国资格 |
| 依薇 | 苏迈政务、船贷与公账抄写 | 娜洛出身旁房，珀岚任市执政；旧富房曾在651年被查隐匿船厂，现不当然免嫌 |
| 韦沙 | 凯兰侯家、骑兵与葡萄地产 | 爱伦守特许，拓岚管理侯堡畿；堂妹韦沙·楠依倡乡审日，对本家庄役也有批评 |
| 绍 | 渊流水官与纸业 | 朗泉任全国议正，稷和任会槽议正，堂兄绍柏笺供纸；采购须回避，亲属关系公开 |
| 江 | 渊流小田联盟、经师与粮贷 | 识穗倡均水，文穗的学寺传承支持祭产迁置；大田旁房反对削旧水额 |
| 佼 | 桑垄织工、雇工互助与公社教育 | 碧葳主持社联，阿绣推动妇户资格；家产以作坊份额为主，无全国世袭议席 |
| 翟 | 苇章王家、宗室学田 | 洪恭支持官学，绍嶽维护宗室庄园，王侄翟稷衡从水土学不享自动官阶 |
| 晏 | 曜廷王家与旧朝宗亲 | 昭辉受新王约限制，叔晏中嵩强调旧廷特权；宗亲不能仅凭血统收邻国税 |
| 审 | 曜廷经师、法官与典籍 | 庭裕修补廷制，族妹审绢灯支持齐灯派；入学资助及婚盟比封地更重要 |
| 棠 | 西承银市、官署与债券 | 与衡统筹公债，慎治管错银市；棠与衡母家为曜津贸易户，跨海亲属不证明叛国 |
| 奈赫 | 北候份船、海救与议盟 | 瑟娅主张共舰，额依管结帆港；雾航旁支不愿按资本份额承担公共舰债 |

郝氏穗台田房的郝笃隆在688年因重复工役败诉，742年领监郝遐隆是其孙，不能把两任隔五十四年的官员当同一人；孙房承田债而不自动承祖父官职。

### 姓称与家谱的读法

阿苏特、苏勒沁和塔拉沁保瓜凉名谱的长短音，旧官簿常省尾记族称，不能再据省音合并不同家门。阎、郝等单字姓来自早期双语登籍，旧契的颜、贺字形与后来的名谱相互校读；绍氏水官、江氏小田、佼氏机份家产各有具体传承，不由姓字本身授官。晏氏旧朝宗支与审氏学舍、棠氏海贸房的名字也须与各自契书相合，不能把同一个常用姓字扩成跨国的单一资产所有者。

芦赫和七斗名谱多分家门与个人两栏，通用译文用间点相连；家谱后抄本可能以晚起房名称祖先，早期本义未明者不凑汉字寓意。奈赫的收养份船房、艾珊灯师与渔户的非同室记录，说明全名相近仍要查父母、配偶、收养和年代；家门的声望能影响选举，却不能取代依法任命。

## 二、政治、军事、商业与专业权力

政治家门把学校、婚盟与保举结合，军事家门依赖军官训练、马场和赏田，商业家门凭货栈、船份及债务网络，大地主家门掌水额、仓粮与地契，宗教家门靠弟子、祭产和解释权。还有纸师、药师、桥匠与口译家门：栎氏世代校水尺，鄦氏苇章学田刻版，浦氏擅长双语水讼，芦赫露沙诸房熟染料，却不是天生拥有行业知识。

653年栎家桥匠栎真宁收无姓孤儿为徒，工尺传给通过造桥验算的学徒，技法传承依据训练而定。后来“栎派”指技法传承，登记中有四姓。相比之下，曜廷审家经师常优先资助亲属，使公开考试仍偏向有家学者。亲属资助与技术师承各自提供行业延续渠道。

## 三、庄园与资产的实际边界

阿汶·鲁延家在腴岸拥有约一万八千受税亩，但只有六千亩为直接耕作，其余租给二百余户、共有苇荡或低洼季田。其田产包含直接耕地、出租田、共有苇荡与季田，米租收益按不同地块核算。韦沙家葡萄地产附带旧乡调停权，没有合法扣押雇工生命的权力；非法私牢在709年巡判案中被拆，罚款后家族仍保留大部分土地，这比“一案便推翻贵族”更接近权力运作。

商贷也会分化家庭。依薇船贷房给盐枝港堤工放款，公簿披账派娜洛要求连带披露，受到长房指责。她赞成公开不是因为脱离所有家门利益：降低国家借债利率同样有利于她的造船伙伴。政治动机不必只剩自利或无私两项。

## 四、婚盟、外籍与衰落

680年棠家与北候奈赫支家合建灯油仓，婚姻使两边理解继承习惯，但项目仍以契约规定亏损；女子棠文汐保留独立份船，并非嫁入便由夫家占有。723年失船后，两家争吵了三年才由航约判庭裁决。文化熟悉减少了翻译成本，没有取消财产冲突。

旧凯兰开国家门在四世纪绝嗣，韦沙家经继承契取得侯位，国名未改。鄂勒温盐驿富家穆罗房在622年盐井枯竭后分散为市社职员，没有每个历史大姓都无限长存。贵族家谱常掩去破产、收养与无地旁房，志书把这些纳入才能避免把现代势力写成从古至今连续不变。

## 五、归纳评价

家门影响依土地、粮贷、船份、学校、婚盟和师承资源延续，政治官位与私人资产分别登记。旁房、收养、异姓学徒和破产改变了这种延续的方式；同一家门在不同事务中可以支持不同政策。采购回避、财产分账和独立证据，构成公共机关处理家门关系的主要程序。
