# 世家志 · 岚衡大陆

> 《西湾盛洲志》第一卷。记述时点：共历742年秋。

[返回志纲与总目](../../00·志纲与总目.md)

家族以主要权力来源分类，实际常跨越数种行业。主支、地方旁支和贫弱亲属的资产及任职资源各不相同。

### 1. 政治家族

| 家族 | 国家 | 权力来源及倾向 |
|---|---|---|
| 宁氏稽京支 | 越宁 | 王位、王庄与任官权，主张继承大宁正统 |
| 沈氏 | 越宁 | 教育、门生、赋税与考核官僚，支持统一税制 |
| 宁氏澄都支 | 澄川 | 世袭国君，与越宁同宗而不受其册封 |
| 陆氏 | 澄川 | 议席、阶地庄园与粮运，维护世家共治 |
| 韩氏 | 临海 | 海防统帅起家，依赖舰队、关税与港城合作 |
| 乌梁氏 | 巴梁 | 王田与盟誓，须得到主要氏族承认 |
| 维罗家门 | 罗勒 | 法律、外交、议会联盟与跨城分支 |
| 萨维安氏 | 萨汀 | 洛萨旧王室、王庄与贵族神庙支持 |

### 2. 军事家族

戚氏影响越宁北稽军屯、马政与军官网络，但不在法律上私有全部边军。石门岩氏控制重要守峡与巡船力量，并受城议事会约束。白岭氏以山口、城寨和军役盟约维持巴梁地位。德拉文氏拥有萨汀庄园骑兵、军马与边堡，要求保留贵族司法和军役特权。

### 3. 商业家族

温氏经营临海远航、合伙和海上借贷，在罗勒湾有商馆；船队中不少是合伙财产。程氏经营澄川仓库、驳船和转运。莫兰家门办理罗勒汇兑、海运贷款与公共借债，在临海、澄川有代理。铜谷氏连接巴梁矿主、冶炉、商队与军械官。

商馆业务主要覆盖岚衡七国，与另外两大陆的往来规模较小。

### 4. 大地主家族

顾氏掌镜泽圩田与堤防组织；陆氏掌澄川较安全的阶地庄园；塞兰家门经营罗勒橄榄园、葡萄园、油坊与酒窖；阿尔登氏经营萨汀谷物庄园和蓄水设施。

地主权力往往来自共同水利、劳动力和市场，而非单纯土地面积。

### 5. 宗教家族

奥瑞恩家门通过教育、婚姻和神庙人事反复取得高位，但最高祭职不依法世袭。雾松氏保存本地山林盟誓和边界。贝氏保存白牙祀母系祭职。赤砾氏兼育祭师、探矿者和工程师。泉照家族保存分水惯例，祭职可传女儿或认可的收养者。

### 家族分支与行业依附网络

“沈氏派”“温氏派”是识别稳定网络的简称，各分支在具体议题上仍有分歧。沈氏清丈官依靠准确田册升迁，沈氏嫁入大田庄的一支却可能反对追查隐田。顾氏堤工管事愿接受核费，靠水租获利的支房更怕重新界定受益田。742年清丈争论因而能把亲属分在两边，也能使竞争家族就某一条复核程序合作。

温氏长期放款人要求舰债按期还本，经营短程货运的一支更愿关税减轻；柯氏大厂欢迎规格统一，小坊担心候验与垫资。铜谷矿契经纪支持安全记录以降低争讼，押有高息矿债的成员却可能逼矿主早开井。家族总管维护共同名誉，各支投资仍有不同收益和风险。

奥瑞恩家门凭教育、捐资和姻亲持续影响天尺院，祭司职位仍须按院规取得。家门中未入祭职者可经商，入祭职者也会反对亲族扩大庙庄。泉照家族保存分水旧例，水次变更须经居民议事。贝氏祭系继任则依母系资格、学习和岛议认可确定。

许多长期支撑大族的人不使用其家名：账房、奶母、驮队头、佃户领头和译证人构成另一层网络。某位领头者改换保护人，足以使一个庄园缺劳力或一条货路停运。世家史只记婚姻，容易漏掉这些没有进入族谱的关系。

### 三次跨文明关系的不同结果

铜山学徒炉石阿穆被东门塞兰·薇诺收养，铺面传承得到认可，墓祭另议；这是一桩契约与亲属结合的个案。寒枝牧群与越宁关吏订越冬约，双方没有合并氏族，也没有变更国籍。阿兰家门招收多地驮队成员，城籍与家门籍仍并存。收养、季节协作与职业接纳都能跨越文明，其法律后果却不相同。

### 归纳与评价

家族通过婚姻、师承、债权和照护维系。谱系可以辨认亲属与时代，各分支的政治选择则受投资、职位和义务影响。
