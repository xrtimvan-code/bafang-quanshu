### 1. 人口与城市

| 国家 | 人口估数 | 主要分布 |
|---|---:|---|
| 越宁 | 1400万 | 稽水平原、堤围聚落 |
| 澄川 | 420万 | 阶地、汇流地带和河镇 |
| 临海 | 400万 | 港城、沿岸与岛群 |
| 巴梁 | 520万 | 梁城盆地，边山较稀 |
| 玄峡 | 180万 | 谷底盆地、渡口和台地 |
| 罗勒 | 330万 | 港城及农业腹地 |
| 萨汀 | 310万 | 谷地、泉地，高平原分散 |
| 合计 | 3560万 | 流动居民和无籍者容易漏登 |

约八成人口居乡村或农业小镇。临海、罗勒城市人口比例较高，仍未超过三分之一。稽京约四十万，潮安与罗勒城各二十余万，澄都与梁城十余万。

城市须持续输入粮、燃料和水。中断运输数周即可引起显著涨价。

### 2. 族群与文字

会稽平原稻农、镜泽湖民、北稽居民和沿海船民生活不同；巴地盆地、寨区、峡谷和牧民身份不同；罗勒港城、庄园、台原和泉地亦然。

澄川西部、巴梁山口、玄峡南关、罗勒东门多混居和双语家庭。文明认同在婚姻、迁居和职业接纳中形成多重层次。

会稽士人共用稽文，口语差异仍大。巴语诸方言以梁城话渐作贸易通语，盟约古语须誓书官解释。罗勒与萨汀共用正式文字，口音词汇已分化。

成年人口约一成能读简单账目告示，熟练长篇写作更少。书吏、祭师和族中识字者因此经常替他人解释契约。

### 3. 身份与自由

王室、贵族、大族、官员、祭司、自耕农、佃农、工匠、雇工和流动居民并存。政治权依户籍、会籍、公民籍或家族席位取得，财产状况与法律身份分别影响居民生活。

越宁以户籍约束税役与迁徙，军户有一定世袭职责。澄川全国议席由既定世家掌握。临海区分本城有资格居民、登记外来者和短期居留者。巴梁人的保护常依附氏族接纳。玄峡居民到别城不自动取得议事资格。罗勒富裕外商不自动成为公民。萨汀部分庄园依附农户迁离须经许可，泉地新来者不自动取得分水份额。

奴隶、债役、刑役和战争俘虏依附仍存在，规则各国不同。罗勒、临海、萨汀部分地区允许某些境外或战争俘虏买卖，通常禁止直接把本国自由居民卖为永久奴隶；执行并不稳定。会稽更多见定期债役与刑役，巴地俘虏有时可经赎偿、婚姻或盟誓入族。

### 4. 生产与贸易

| 国家 | 主要输出与收入 | 重要依赖 |
|---|---|---|
| 越宁 | 稻米、织物、茶药、木材 | 金属、军马、海盐 |
| 澄川 | 纸书、加工、转运、仓储 | 上游木材金属与通航 |
| 临海 | 盐、鱼干、船舶、海运 | 粮食、船材、铁与绳料 |
| 巴梁 | 铜铁、军械、木材、盆地粮 | 盐、精细织物、海运商品 |
| 玄峡 | 运输、纤运、林产、少量矿物 | 粮盐与贸易稳定 |
| 罗勒 | 油、酒、海运、金融 | 木材、金属、部分谷物 |
| 萨汀 | 谷物、战马、酒、金属 | 船材、海运及工艺品 |

七国内部贸易远比与另外两大陆的往来密集。河运封锁会抬高临海粮价，巴梁限铁会影响造舰，罗勒信用紧缩会影响临海商船筹资。

### 5. 土地、货币与税负

土地所有、使用、取水、放牧、采矿与收租可以分属不同主体。越宁私人田须参加堤围，萨汀土地与泉水份额未必同时转让，巴梁氏族土地不一定能卖给外人。

七国各铸货币，日常铜钱、小银币和实物并用，大宗贸易按银重与成色结算。黄金主要用于储藏和大额支付。跨境须换算，港口与河城设验银、换钱和异地支付业务。

田税、关税、市场费、矿税、王庄收益和特别征发构成国用。家庭除国税外，还负担地租、堤费、劳役、祭费和临时军需。连续歉收容易引发借粮、抵押、债役和失地。

### 6. 家庭与继承

会稽偏父系继承，子女分产与族产并存，寡妇可管理未成年子女家产，部分商坊允许女儿继业。巴地继承伴随氏族照护、军役和祭职。罗勒家门容纳收养与合伙，女性能持产经商，却普遍缺少全国投票权。萨汀封地常避免分散，旁支子女进入军队或神庙。

婚姻跨教常见，王室、祭司与氏族可能要求下一代承担特定祖祭。继承争执往往在多年后暴露未谈妥的义务。

### 7. 饮食、居住与劳动

东部以米为主，北稽增杂粮；巴地多谷饭、豆、腌菜和熏肉；西部常见麦饼、豆汤、油与酒。贫民食肉有限，鱼和乳品取决于地区。

镜泽常抬高木屋地面，玄峡依山叠建，西部重石墙、院落和蓄水。衣料以麻、毛及植物纤维为主，丝织较贵。

城市有井、沟渠、市场巡查和夜守，但贫民区服务较差。消防依靠街坊、行会和政府；船厂仓库火险高。医家、接生者、草药商和部分神庙承担医疗，疫病管制常与贸易冲突。

稻农生活围绕农时与汛期，船工随航季长期离家，纤夫依靠险滩经验且易伤残，泉民在旱年最关心渠口与取水次序。

### 8. 法律、教育与上升

越宁案件由县、郡至御史或中央复查；澄川可上诉法议院；临海、罗勒有专门商业程序；巴梁、玄峡多先地方调解，再处理跨社群争端。

费用、误工、书吏与证人安全影响诉讼。刑罚包括赔偿、罚金、惩戒、劳役、流放和死刑。特殊审理保有刑罚与复核程序。

家庭初学、宗族学校、神庙和学徒制是主要教育。越宁考试可提供上升机会但成本高；澄川教育发达而政治入口封闭；港城算术、账务、航海、法律能换取收入；巴地知识常依长期师承。

### 9. 治理的实际运作

长官人数有限，长期书吏、村镇负责人、宗族和行会承担基层事务。腐败既可能是贿赂，也可能是公共劳役私用、选择性救济、采购亲族产品和隐税。

亲缘合作的合法性依各国法律和氏族盟约确认。争点在隐瞒利益、损害共同财产和违背规则。

地方反抗通常先表现为拖延报册、少报牲畜、停航、封井、要求复核旧约；中央也多先调查、谈判、调整费用，最后才出兵。

岚衡的历法并未完全统一。下表以季节、农时与航季说明节庆，各地历日的换算见历法与文教志。国礼、地方祭礼与行业节庆可以并存；参加节庆不一定表示加入某教。

| 萨汀红岩、泉地 | 金砂静炉日；旱季前照泉夜 | 矿井停工检查、清点事故；守泉人读分水序，居民夜间清渠 | 天然矿纹陈列、细金工、月泉歌与泉池石刻 |

艺术也存在阶层差别。贵族聘请史诗歌者纪念祖功，矿工的歌却可能讥讽征税和塌方；澄川刻书能传播官定历史，也能传播不被世家喜欢的戏文。悲剧、讽刺和争辩并不只属于某一文明。

重要文学传统包括会稽治水记与家传、巴地口传盟誓史歌、罗勒航记与辩论剧。口传作品允许不同演唱版本；官书常试图固定其中一版，因此“谁的历史算正史”也是文化争执。

跨国传播最活跃的载体是刻书、旅行艺人、船工和婚姻。临海港剧可以吸收罗勒对白，澄川工坊也会复制巴地器纹。风格的传播跨越族群和宗教边界。


### 11. 代表性法律条款与判例

下表选列七国现行法律、章程和盟约的代表条款，以通行语译写。判例人物按案件发生时的身份记述。

| 国家 | 法律或章程 | 代表条文 |
|---|---|---|
| 越宁 | 《田堤令》分堤款 | “主河堤由官督修，圩堤由受益诸户共修。圩费须列用途与账目，不得借修堤名目征取无关财物。” |
| 越宁 | 《军屯条》籍田款 | “军籍、田籍分别造册。将领不得以军户欠役为由私收其田；追役、追税各依所属机关办理。” |
| 澄川 | 《议政约章》新增赋税款 | “新增常年赋与长期军费，须经议政院。府不得以临时费之名，连续征收而不报用途。” |
| 澄川 | 《赤岸费用章》核费款 | “同一笔已验明的交易，不得以改换关目重收同类费用。行会得派代表查核本业公共费账。” |
| 临海 | 《征船章》适航赔偿款 | “征用须记船型、用途与期限。不得命不适外海之船承担外海任务；因违令使用致损，官府偿付。” |
| 临海 | 《牙环特许》船事款 | “礁场、海葬与岛内小额船事依岛议裁断；外来船员得请译证，不得仅因不奉白牙而拒绝听诉。” |
| 巴梁 | 《重盟书》军役款 | “各族按约供兵；延役须另议粮饷与期限。共同领土遭攻时可先救援，事后仍须核明征发。” |
| 巴梁 | 《入族誓约通则》接纳款 | “经本族认可立誓者，得依誓约受保护并承担相应义务；不得仅以非出生本族否定已授权利。” |
| 玄峡 | 《九城盟约》军费款 | “盟主不得私征居民之税；共同负担须按盟议确定，由各城依法办理。” |
| 玄峡 | 《河道共守章》通航款 | “除已议定之防御、抢险措施，不得以私债封阻干流。险滩救人不得先索报酬方施救。” |
| 罗勒 | 《公共采购章》利益款 | “任职者与承约者有家门、债权或合伙关系，须先申报并退出相关评议；亲属关系不当然禁止投标。” |
| 罗勒 | 《商旅保护章》财产权款 | “合法居留者之财产与契约受法院保护，公民资格之有无不得作为拒绝立案的理由。” |
| 萨汀 | 《明泉章程》水次款 | “先保基本饮水，再按季分灌溉。改渠、截泉须经议事，不得由单一庄园自行处分共同水源。” |
| 萨汀 | 《天尺领界约》属地款 | “捐赠地产不自行移转居民司法与税籍。神庙领外之庙产，仍属所在地方行政。” |

判例不会在所有国家都具有同等约束力。罗勒法院较常引用前案，越宁官员重法令和复核意见，巴梁则重相同盟约是否适用。

| 案件 | 地区、人物与争议 | 裁断及意义 |
|---|---|---|
| 长堤圩费案，701年 | 镜泽顾氏管事顾庆沅向未受该堤保护的高地农户征费，农户代表杜禾起诉 | 判决取消该部分费用，但受益圩户仍须缴费。明确公共名义不能无限扩大收费对象 |
| 落帆重验案，716年 | 澄川河镇以货物换船为由再次收验费，承运人程小舟申诉 | 换船未改货物且凭证有效，不得重收同类费；破损、增货可重新查验。规则兼顾通航与查缉 |
| 灰燕号失船案，729年 | 临海军官强令近海船灰燕号赴外海，船东林汐与船工家属请求赔偿 | 船型记录证明不适航，王务机关付赔并追究军官责任；征用未因此被普遍废除 |
| 青寨入族案，707年 | 巴梁婚入者禾木已立誓并长期服役，原首领死后，新首领拒认其耕地资格 | 誓书与证人确认接纳有效；保留使用权，不赋予向族外卖地权。成员身份不全取决于出生 |
| 双瀑封纤案，733年 | 商人向欠债船主追款，雇人堵塞公共纤道；船工代表藤守索控告 | 私债不得阻断共用通道，恢复纤道并赔偿直接损失；债权可另向适当法院追偿 |
| 银岬缆索采购案，721年 | 港务评议员莫兰·伊索参与决定自己持股工坊的合同 | 合同须独立复核，官员被撤去该项评议资格并罚款；供货质量合格不抵消隐瞒利益 |
| 明泉新渠案，735年 | 南谷庄园管事阿尔登·费恩未经议事改渠，减少居民饮水 | 停止新渠取水、重定水次并修复损害；并未把庄园全部土地交给守泉人 |

这些判决写出的是得到执行的处理结果，不代表所有人都同样容易维权。能够筹集旅费、取得证人和保留文书，是当事人胜诉的重要条件。

### 12. 三户人家的年度压力

以下典型家庭依据地方制度与普通价格复原，分别呈现租田、炉工和泉地居民的负担。币名、价格基准与收支明细见经济与赋役志。

**镜泽杜汀娘家。**734年家中部分租田进水，丈夫修堤，杜汀娘带女儿替邻户补网。米税可以申请减免，地主地租、借种粮和堤围费用却由不同程序决定；各项负担合计决定全家是否有足够过冬粮。她734—736年的申诉借助工役簿、邻户证明与旧租单。租单有用，也会暴露地主此前少报的租田，所以地主未必愿意替她作证。如今她让女儿学认数目，首先是为了读明借粮与工钱。

**铜山炉石阿穆的原生家庭（676年历史复原）。**阿穆后来在罗勒被收养，其留在铜山的兄姊仍履行本地氏族义务。家中靠炉工钱、轮种地与族中救济渡过停炉季。搬去港城的弟弟寄回工具和少量财物，族人认可他的照护，却争论他是否仍有资格分下一轮林地。跨文明迁居没有一次切断原籍关系，反而产生两地同时期待贡献的负担。

**明泉泉照·塔娅家。**她有少量田与一份季节分水资格，丈夫出身台原车匠家庭，不担任月泉祭职。旱年基本饮水受到优先保护，菜地灌溉仍会减少。丈夫外出修车，可增加现金，却使清渠役主要落在妻子和邻户身上。泉照家名有助于找守泉人说明旧例，她仍按共同水次取水；若以亲缘插队，其他泉民反而更容易提出抗议。

### 13. 女性、青年与非正式参政途径

许多全国议席由成年有产男性或既定家族掌握，女性仍可通过持产、主持作坊、遗产诉讼、祭系和救济组织影响公共事务。贝氏女性的祭职、塞兰寡妇的承业权依各自地方程序取得；船团指挥和全国投票权另有资格限制。

青年外出学徒时通常由家长、师傅与担保人订契。约定食宿和学成期限，仍可能因师傅拖延授艺起诉。给大厂做杂工的人未必成为正式学徒。盐灶、纤道和农忙中都有未成年劳动，富户能够送子女读书的优势从少年时期便开始积累。

流动船工、季节牧人和没有固定田地的妇女，最难向官署证明“属于哪里”。他们常保存工签、雇契和救济名单，比普通族谱更有实际用途。灾册补登、翻译证词、伤亡名册这些看似细小的文书变化，决定了某些人能否被国家看见。

### 14. 饮食、礼物与跨地区交往

接峡婚宴的席次往往先按担保家排序，再考虑男女长幼。铜山首炉宴先给巡井、送风与出炉者留份，商队首领坐前席也不应侵占工份。罗勒港城家宴把合伙学徒叫作“门内人”，到了公民登记仍须查独立资格。同一称谓在家中、行会与官署可有不同含义。

跨地区赠礼容易产生误会。白岭人送一截结绳，可能表示愿意护送一段道路；港城商人若当作长期保险凭据，出了事故便会争执。译官的工作不只是换词，还要说明承诺期限、对象和由谁承担。混合交易话适合议价，涉及收养、分水和军役仍需更严谨的文书。

城市饮食常比礼法混合得快。潮安船工吃米粥配西海油渍鱼，梁城客栈出售麦饼夹熏肉；昂贵舶味先在商人宴席流行，后来出现本地替代品。穷户日常菜单变化小，节日食物却能借邻里互赠跨过身份边界。菜肴的传播与文明认同按不同节奏变化。

### 诉讼、身份与行会的具体程序

普通民案先向所在地县、城或寨登记，可口述由书吏写状；书吏须宣读确认，译证记名。案件分立案、传唤、核证、听断、执行五环，判决后仍有执行、验款和支付环节。小额债案一般两旬内首次听审，严重刑案不可照民间调解私了。收据、见证、物证与现场查验分别核实。家族权势可能影响实际采信，须结合审理和执行记录考察。

越宁县判上诉郡，重大死刑经刑署复核，灾年行刑可因证据不足缓办而非必得赦；澄川府案上法议院，陆氏庄园涉案须换无直接利益的议员审理；临海港务法庭审货船案，杀伤案仍属王国法院体系；巴梁寨内依旧约初审，跨族或入族资格争议由誓书官与两方代表共同审，王廷只在重罪与盟约冲突介入；玄峡城法庭上盟约庭仅限跨城或共同章程事项，本城婚产案由城法庭处理；罗勒地方法院上高等法院，参照前案仍须说明事实相同；萨汀领法院上王领巡判，祭师不得仅因案件发生在庙庄就排除王国严重刑事管辖。

被告可请具名代诉人；穷户从义仓或行会得到写状费，通常不能获得全程免费律师。羁押应记日期与缘由，每旬核一次；港城外来者可用担保候审，逃逸风险高者仍拘留。刑讯在严重刑案尚被允许，但七国都不以单独口供作为执行死刑的充分证据。罗勒583年后的公账案优先书证，越宁地方亦有滥刑追责；相关限制在各国司法程序中逐渐形成。

永久奴役、债役与庄园依附分别记。越宁和澄川普通债役约最长三年，役所得须抵债，债主不得把同一债续写成终身；刑役依罪期另定。临海与罗勒战争或境外奴隶的身份买卖须登记原籍与来源，禁止偷卖本国自由居民，港口伪造外籍证仍是严重现实。巴梁俘虏赎身、立誓入族或服约期可改变身份；萨汀依附农户附着庄园劳役，通常有自用田与成婚权，不等同可拆散售卖的家奴。红岩矿契禁止以抵债为名把自由工人永久送入危险井。

婚姻财产须区分个人带入、共同取得与族产。寡妇代管未成年子女份额，族祭田的处分仍需本族认可；夫妻分居须核子女照护、债与嫁资。跨教婚契记录子女祭礼和墓地约定，但不得强迫未成年者永久充祭职。继承与公民票权分别取得，法院认女子承业不自动赋全国选举资格。

行会分资格、买卖、互助三种功能。柯氏所属船匠会章规定三年学徒后经两名非亲师傅验样、每年收会费工资约二日、伤工箱由订单额百取半；大厂不得用不许转师控制全部学徒。赤岸纸会要求排水沟与取水口分离，行会可停止不合样纸出售，却不能自行囚禁工匠。双瀑纤会规定险滩先救人、救援费事后按共费核付；银岬货会必须公开会首与承包者合伙关系。外来人申请入会须住满一至两年并有担保，部分会仍不接纳女子为正式师傅，改革争点就在这里。

行会章受国家法律约束。会内罚金有上限，逐出会影响工作资格但不撤销居民财产；会首涉及伤害、绑架或公共封路，必须交法庭。公共收费、行业自律、商人限制竞争有时混在一张章程里，官府按公共收费、自律和竞争限制分别复核各款。

### 归纳与评价

普通人的谋生横跨田地、工钱、亲属与互助组织。新法能够提供申诉理由，识字、证人、旅费与执行仍决定能否使用；跨族饮食与婚姻扩展交往，继承与政治资格则改变较慢。
