# 行旅志 · 衡岑大陆

> 《弥洛洲志》第一卷。记述时点：共历742年秋。

[返回志纲与总目](../../00·志纲与总目.md)

### 1. 三条主要联系轴

东部河运轴由迭嶂经让陂、沅稽水平原至胥泊；中部山道由腊川经勒贡通让陂，另向西通勒汶提萨门；西海航运轴联系勒汶诸港、纳洛伊列岛和瑟铎沿岸，再向南部海域展开。

后者说明衡岑内部与近海航运，不等同与另两大陆已有固定密集航线。

普通农户活动常限村落、集市和祭所，商人、官员、军人、朝圣者更常跨国。

### 2. 路线与进度

让陂城至允沅京水路约650公里；乌腊城至让陂城跨山路线约900公里；勒汶城至瑟铎堡陆路约700公里，均为实际路线粗估，非直线距离。

| 方式 | 一般每日进度 | 限制 |
|---|---|---|
| 徒步 | 20—30公里 | 天气、住宿、负重 |
| 山地商队 | 10—20公里 | 山口、牲畜、关卡、滑坡 |
| 平地车队 | 15—25公里 | 道路、桥梁、饲料 |
| 接力急递 | 80—120公里 | 驿站、换马与优先权 |
| 河船 | 顺流40—80公里，逆流较慢 | 水位、风、险滩、纤道 |
| 海船 | 顺风百余公里 | 候航、补给、风暴 |

允沅京到让陂城沿沅稽水顺流而下，顺风时可十余日；返程逆流，若遇候水或沿途检查，可超过一月。军队行进需组织粮车和驮队，速度慢于信使，边境收到命令取决于驿路和送达时间。

### 山口货运的凭证与收费

从乌腊城运铜往洑隈埠，商队先备矿契和货单，再找驮队担保过岭。路过氏族领，王廷凭证可证明货物来源，却不自动免去已议定的护路费。进入迭嶂后，须分清共同航段费用与某城仓储费，628年自由航段约禁止的重复收费仍可申诉。下行到让陂，换船而货物未变者可据716年洑隈河镇案要求不重收同类验费。

一名背夫通常不掌握全套文书，他知道的是雇期、口粮、伤病由谁送返。商队账目若只记货损，便会漏掉背夫在岭上病倒后的费用。史家读“货如期至”，还须核同行者的伤病与送返情况。

朝圣者的祭仪身份与过境身份亦不同。祖山接待所会问行列时间、人数、所需译证和住宿，国家关吏仍可能查携带的商货。白牙信徒从瑙黎入山需要两次以上交通安排，许多人一生未亲到阿绰祖山；在本岛正式认祖，体现地方与祖山的祭仪联系。

### 3. 旅途中的等待、接待与救济

货队出发前先分人账与货账。人账记领队、雇期、担保、口粮与伤病送返；货账记件数、封记、所有者与付款节点。雇工责任以雇契为限，商人货物债务由原签主体承担。大队通常设熟路人、账手、牲畜照料者和轮换夜守，小队则由同一人兼任；护送者熟悉哪个寨的承诺，比只会持刀更有用。带老人孩子迁居者常随粮车同行，另约候车与住宿日程。

客店、寺舍、行会宿屋和亲属借宿各有资格。官驿主要接持公凭者，普通商人无权要求换马；货栈供铺位却未必供家庭隐私。基层接待先问住几夜、谁担保、携何货，再核原籍凭证。妇女或无田船工可用雇签、船籍与邻保说明身份，不一定持族谱。译证者在按印前宣读付款与赔偿条款，为不识文字的客人留下具名见证。

候验和候风构成行程成本的重要部分。驮货在洑隈河镇换舟，须等凑足货批、干燥包装和查验；到仓后仍须等待查验和登船安排。港口候风可能延数日或数周，船工仍吃粮，家属也在等寄款。风向合适但潮口不合，船只能再候一潮。商馆记录“启帆日”时，通常不包含此前住岸的日子；全程成本合计航行、岸宿、仓租、候验与误工。

### 4. 迁居与索赔的行程

**喀石禾木到勒汶提萨门。**672—678年收养案已确定他的迁居与继业，其迁居行程依案卷记载的程序复原。喀石禾木离喀木时要带师傅认可的授艺说明、原氏族担保与工具归属单，沿腊川转运至西向驮路，再入提萨门工坊。塞莱俄·维诺娅的接纳能给他住处和学徒工作，原籍未结的照护义务仍须履行。到境后先作居留登记，随后办理收养与铺面契；公民资格仍须另审。途中若工具损坏，关键是它属于师傅借物还是学徒自有财，收养契与原运输责任分别处理。

**霖昀往返芒鹭与胥泊城。**729年鹭汐号案中的船东要证明船型不适外海，家属要证明船员受征和失踪，二者证据不同。本节将既有诉讼材料中的程序串成查证行程：芒鹭的船籍与近海作业记录须送胥泊城，港录的征用单又须回原埠找邻船作证。地方领航者可以说明船的实际能力，却不能替王务机关确认赔款。家属来回失去捕鱼和补网工日，获得赔偿前可借行会伤亡箱垫食宿；没有会籍者只能另找担保。胜诉是支付的起点，查验身份、划分船损与家属补助后，钱才逐笔兑现。

旅途事故首先救人，再记财损。峡道救援由近旁纤工和城救险人员合作，海难由灯标户与救艇接应；账上须分别列临时口粮、药布、遗体或伤员送返、船货保管。救援者可追合理成本，不能先占货再讨论救人。死者未留家属时，雇签与同行证词仍应留存，免得“无人领款”最终被写成“没有死者”。

### 归纳与评价

路线的通行季节受水位、积雪和风向限制，沿海航行、险峡换载和远洋候风需要不同知识。旅行者须准备身份、译证、担保与季节余粮，并计算住岸等待、家中误工和事故送返；到达与取得居留、继业或赔付资格也非同一步。里程按实际路径粗估。
