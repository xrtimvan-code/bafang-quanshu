# 世家志 · 衡岑大陆

> 《弥洛洲志》第一卷。记述时点：共历742年秋。

[返回志纲与总目](../../00·志纲与总目.md)

家族以主要权力来源分类，实际常跨越数种行业。主支、地方旁支和贫弱亲属的资产及任职资源各不相同。

### 1. 政治家族

| 家族 | 国家 | 权力来源及倾向 |
|---|---|---|
| 郢氏允沅京支 | 允沅 | 王位、王庄与任官权，主张继承郢承正统 |
| 申莘氏 | 允沅 | 教育、门生、赋税与考核官僚，支持统一税制 |
| 郢氏让陂支 | 让陂 | 世袭国君，与允沅同宗而不受其册封 |
| 禄氏 | 让陂 | 议席、阶地庄园与粮运，维护世家共治 |
| 邗氏 | 胥泊 | 海防统帅起家，依赖舰队、关税与港城合作 |
| 乌腊氏 | 乌腊 | 王田与盟誓，须得到主要氏族承认 |
| 维鲁恩家门 | 勒汶 | 法律、外交、议会联盟与跨城分支 |
| 萨维铎氏 | 瑟铎 | 罗萨特旧王室、王庄与贵族神庙支持 |

### 2. 军事家族

祁弋氏影响允沅祁护军屯、马政与军官网络，但不在法律上私有全部边军。岩泷氏控制重要守峡与巡船力量，并受城议事会约束。勒贡氏以山口、城寨和军役盟约维持乌腊地位。德拉维克氏拥有瑟铎庄园骑兵、军马与边堡，要求保留贵族司法和军役特权。

### 3. 商业家族

缊氏经营胥泊远航、合伙和海上借贷，在勒汶湾有商馆；船队中不少是合伙财产。乘氏经营让陂仓库、驳船和转运。莫拉提家门办理勒汶汇兑、海运贷款与公共借债，在胥泊、让陂有代理。喀谷氏连接乌腊矿主、冶炉、商队与军械官。

商馆业务主要覆盖衡岑七国，与另外两大陆的往来规模较小。

### 4. 大地主家族

沽氏掌沫澥圩田与堤防组织；禄氏掌让陂较安全的阶地庄园；塞莱俄家门经营勒汶橄榄园、葡萄园、油坊与酒窖；阿勒敦氏经营瑟铎谷物庄园和蓄水设施。

地主权力往往来自共同水利、劳动力和市场，而非单纯土地面积。

### 5. 宗教家族

奥瑞昂家门通过教育、婚姻和神庙人事反复取得高位，但最高祭职不依法世袭。乌梢氏保存本地山林盟誓和边界。瑙贝氏保存白牙渡母祀母系祭职。砾托尔氏兼育祭师、探矿者和工程师。伊勒莎家族保存分水惯例，祭职可传女儿或认可的收养者。

|---|---|---|

| 让陂胥氏 | 造纸刻书 | 水力作坊、刻工、书院客户 |
| 乌腊喀石氏 | 铸造军械 | 冶炉投入与长期技术训练 |

| 允沅闵氏 | 医药 | 师承、药材渠道与声誉 |

### 家族分支与行业依附网络

“申莘氏派”“缊氏派”是识别稳定网络的简称，各分支在具体议题上仍有分歧。申莘氏清丈官依靠准确田册升迁，申莘氏嫁入大田庄的一支却可能反对追查隐田。沽氏堤工管事愿接受核费，靠水租获利的支房更怕重新界定受益田。742年清丈争论因而能把亲属分在两边，也能使竞争家族就某一条复核程序合作。

缊氏长期放款人要求舰债按期还本，经营短程货运的一支更愿关税减轻；柯罗氏大厂欢迎规格统一，小坊担心候验与垫资。喀谷矿契经纪支持安全记录以降低争讼，押有高息矿债的成员却可能逼矿主早开井。家族总管维护共同名誉，各支投资仍有不同收益和风险。

奥瑞昂家门凭教育、捐资和姻亲持续影响伊萨尔院，祭司职位仍须按院规取得。家门中未入祭职者可经商，入祭职者也会反对亲族扩大庙庄。伊勒莎家族保存分水旧例，水次变更须经居民议事。瑙贝氏祭系继任则依母系资格、学习和岛议认可确定。

许多长期支撑大族的人不使用其家名：账房、奶母、驮队头、佃户领头和译证人构成另一层网络。某位领头者改换保护人，足以使一个庄园缺劳力或一条货路停运。世家史只记婚姻，容易漏掉这些没有进入族谱的关系。

### 三次跨文明关系的不同结果

喀木学徒喀石禾木被提萨门塞莱俄·维诺娅收养，铺面传承得到认可，墓祭另议；这是一桩契约与亲属结合的个案。胄拉牧群与允沅关吏订越冬约，双方没有合并氏族，也没有变更国籍。阿拉赫家门招收多地驮队成员，城籍与家门籍仍并存。收养、季节协作与职业接纳都能跨越文明，其法律后果却不相同。

### 一支商家五代人的聚散

莫拉提在官书中常与汇兑、海运贷款并称，家藏婚约与分产札却表明，并非挂此家名者都经营同样买卖。五百年代初居勒汶的一支，先有短程收货与保管零钱的铺面，随后才替较熟客人把钱送到异城。莫拉提·瑟安约512年仍亲自清点货袋，不愿为未见过的远行船队担保。他的姊姊嫁到胥泊后，介绍港内修帆、供绳者，家门才有了不随一条船生死的常住联系人。后来的家记将开馆归功于瑟安，实际上姊姊介绍谁、替谁解释、在哪几次争执中愿意出面，比铺门悬了什么姓号更能说明早期信用怎样建立。

瑟安的长子擅算，却不愿在陌生港口长住；女儿莫拉提·利娅愿意过海，531年前后已替家中核短程货物。父亲准她带去存货，不肯把勒汶祖铺也作抵，声称远地事情不可累及守家者。利娅起初认为这是不信女子经营，后来一支由男性表亲主持的远航请求连保，同样遭拒，才明白父亲也在保护另一群依祖铺生活的人。她并未因此不再反对父亲：若海外生意盈利要分给本家，亏损却全由在外者承担，家门便把共同与各自两种说法用在最有利的时候。

利娅与兄长在约538年分订一份往来约，祖铺借出的货先定价，海外利润另计，不再每次都以家内奉命解释。几个侄辈后来嫌约太细，说一家人何必处处写明；负责替他们清偿一笔误寄货款的叔母却坚持留下。亲属感情既可降低起步时找人的成本，也使损失不易当面追问。写下义务没有终结感情，有时恰好让争吵不必上升为不孝或背亲。此后两家仍共同祭祖，但女儿的一房逐渐有了自己的雇工、姻亲和择业习惯。

第二代莫拉提·维岑约550年代接手部分海运放款。他相信常做一条熟路，得利有限，愿把盈利再押到新航次。其堂弟莫拉提·诺安经营近海粮货，宁愿以较低利润换较快周转，两人在一场祖祭后争论到半夜，长辈责他们把钱话带进祭席。维岑说子孙须留下可扩大的家业，诺安说能使下一代不受债主摆布便是家业。两人所重都包括家庭长久，并不能简单分为进取与保守；他们要养活的家属、可承受的损失和熟悉的知识不同。

约562年一轮货运失利使维岑无法按时付还几笔款，诺安不肯拿全部存粮相救。家记将其写成堂房失和，雇工却记得诺安先付了自己铺内两个月工钱，免得救人以后连本铺也停。维岑抵出一处仓位，有位不姓莫拉提的老账房仍愿留下处理余款，条件是不得再以新货款填旧支出。那位账房没有因忠于旧主被收作家人，几年后自开小铺，带走几名熟工。家门一度失去仓与人，旧主人未被完全逐出行业，也未能把所有跟随者留在族内。

第三代的莫拉提·艾汀在祖辈挫败以后入行，约590—610年代长期往来让陂。她没有继承完备商馆，而是借乘氏一处仓隅存货，再靠替双方来客传口信取得收入。艾汀与乘氏旁房结亲以后，居处和业务仍分别核认；丈夫的兄弟想用她的海外关系推销一批滞货，她拒绝，又不能在每次祖祭都避开对方。婚姻创造介绍和信任，也把难以退出的请求带进日常。所谓两家联姻支持同一政策，多半只能说明某些人有了更频繁见面的机会，实际的同意仍须重新取得。

艾汀的长子幼时想学礼文，母亲起初希望他认货、记价，后来允许他进入让陂讲席。他在约621年给家中的信里批评富商将捐庙看作换来身后好名，自己却不愿代母亲去问欠款，称追逐钱财妨碍敬神。艾汀答说讲席的灯油也由别人劳作供给，若学生拒管来源，正好让所依靠的关系不被看见。儿子没有据此改行经商，几年后回到港馆为病客读家信，继续坚持捐献不能抵偿平日苛待雇工。母子冲突未由一封信解决，后来形成的合作，也保留了两人对虔诚的不同理解。

这一房的信件显示，信仰不只是商人算计利益的外衣。艾汀在一次丧子后停掉原已谈妥的扩馆，愿留钱维护送亡仪式，合伙人认为她错过时机，她仍坚持。数年后她又将一部分仪费改为供长期候航的家属吃食，并未因此不再相信亡者需要引渡。仪式的花费、亲属的悲痛和经营判断彼此影响，不能由结果赚了还是亏了断定其相信得真不真。宗教家门与商业家门的往来，同样须看信念、关系和制度怎样共同作用，而不只计算捐款换到几个职位。

第四代在六百四十年代分家时，家中已经有能独立经营的数处业务。最大争执不是哪位儿子承祖铺，而是外甥长期代管的港馆算亲族资产还是合伙。他成年后从未住在祖铺，许多客户只认他，祖谱却将其多年工作称为替舅家效力。最后分产保留本家所有的仓具，把若干客户自行选择继续与谁交易的事实写入交割；他得到较少实物，却有更多旧客愿留。此种安排不是宣布人脉一律可以继承，而是承认商业关系离不开正在服务的人，不能全随一张房契转手。

相较之下，另一名照料祖母多年、没有出门经营的女儿所得更少。分产人说她居家食用已经由公中负担，未把她使兄弟能够长期在外的劳动计入。她离家后投亲住了两年，最终接受一笔固定供养，不再参与祖铺分红。后世若只凭铺业继续扩张而称这次分产成功，便会漏去这一段关系断裂。家族可以在企业意义上繁荣，同时在某些成员的生活中失去承认；财富总额的增长不能替这些经历作统一评价。

第五代约680年代进入行业时，较富的一房已雇外姓账房，年轻主人甚至不熟悉每批货怎样捆扎。另一房还靠夫妻同守铺面，孩子随船亲戚学认岸形。共同姓号使后者偶尔获得暂缓付款，却也使人误以为他们能够承担大房同样的垫资。有小房因一次误保被追款，向大房求援时才知道祖辈口头所称一家，并没有自动成立的连带债。争执以后两房同意继续出祖祭费，生意上互不担保。家门没有解散，能够共同承担的事情却缩小了。

到709年前后，几位莫拉提后辈参与讨论港内放款与公共借债，有人希望国家准许更多关税担保，有人已把资金放在短程粮运，反怕担保压低日常贸易活力。另有不经营钱货的教师、病中亲属和守铺寡妇，只在分家与赡养时同议事者发生关系。742年把莫拉提称作金融家门，描述的是其中较有影响的一部分职业，并不能代替这些后辈的全部生活。瑟安之房早期留下的姻亲、师徒与供养关系，至此有的仍存，有的只在旧信上可见；今日联盟亦须每一代重新维持。

### 小家门的中断与不留姓的传承

大族容易留下可连续阅读的史料，许多小家却在第三代便不见同一姓号。人口流动、收养、婚入和无子女继承，使技艺转到异姓人手，旧铺仍开，名录已变。允沅医馆的配药帮手、胥泊船坞的补帆户、乌腊修具坊的伤工，都可能把最熟的一部分本领教给邻人孩子。家谱没有继续，不代表知识中断；孩子进入更大作坊，也不代表原家劳动已获公平回报。有些手艺后来以雇主家名流传，能够追到的早期劳动者反而只有乳名。

迁居家庭还会主动放弃一部分家门资格。有人为了不再承担原乡无止境的筹款，接受不能分祖田；有人愿继续寄钱，却不肯让亲族决定婚事。接纳他们的城市可能给予居住和营业机会，又设高额入行费用。退出旧依附并无一种标准终局，既可能扩大选择，也可能丢失最后可求助的人。家族制度的变化因此须同时考察留下、迁出、被逐和自行离开者，不能只从成功主支描出一条不断适应的连续线。

### 归纳与评价

家族通过婚姻、师承、债权和照护维系。谱系可以辨认亲属与时代，各分支的政治选择则受投资、职位和义务影响。
