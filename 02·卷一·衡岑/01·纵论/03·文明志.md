# 文明志 · 衡岑大陆

> 《弥洛洲志》第一卷。记述时点：共历742年秋。

[返回志纲与总目](../../00·志纲与总目.md)

### 1. 共同的阿绰衡脊起源

约共历前2200年至前1500年，阿绰衡脊中低海拔谷地有众多聚落，种植谷物、饲养牲畜、采集山林资源，并交换盐、石料与早期金属。山口贸易、婚姻、季节集会和祭仪建立了共同联系。

当时各聚落分别组织生产和祭仪，居民有多种来源。阿绰祖山是重要祭地之一，后来逐渐获得共同祖地地位。后世宗教以“天下先民皆出祖山”表达共同认祖传统；聚落和地方材料显示居民迁徙有多种路线。

此后，人群向东进入平原、在中部盆地与峡谷发展、向西进入海岸，与各地原有居民融合，逐渐形成三文明。

### 2. 会稽文明

早期核心位于岑逵山麓和让陂河谷。山地居民带来谷物种植、冶金与祖祭传统，和沅稽水原有渔猎、稻作居民融合。水利、粮仓、赋税与书面法律主要在平原生活中形成。

| 时期 | 年代 | 主要情况 |
|---|---|---|
| 河邑时期 | 前1500—前850年 | 城邑围绕水利发展，合作与河道争夺并存 |
| 沅稽旧国 | 前850—前280年 | 首个大型国家，统一部分历法、文字与水利征役 |
| 郢承王朝 | 前280—318年 | 统合让陂、沅稽水平原与主要海港，是会稽最大旧国 |
| 三国时期 | 318年以后逐步形成 | 允沅、让陂、胥泊分别继承不同地域与制度 |

允沅于318年在允沅京重建宗室朝廷；让陂于327年由世家拥立另一宗室支系；胥泊于346年由沿海海防统帅建立王室。

会稽共用稽文，重视成文法律、祖祭与宗族。其内部平原、湖区、北部旱作与海岸居民差别很大。

### 3. 巴文明

形成于腊川盆地、阿都丘陵和迭嶂山地。盆地供粮，丘陵控制梯田与林地，矿区供应金属，峡谷承担运输，产生氏族盟约与地方习惯法传统。

| 时期 | 年代 | 主要情况 |
|---|---|---|
| 寨盟时期 | 前1700—前900年 | 城寨联盟，盟主主要主持战争、道路与祭仪 |
| 巴川旧庭 | 前900—前360年 | 以乌腊城粮食与矿贸统合盆地，对峡谷依靠贡赋 |
| 赫腊王国 | 前360—271年 | 统合矿区与山口，向迭嶂派官，王权与地方冲突增加 |
| 两国时期 | 284—289年后 | 乌腊重建盆地王权，迭嶂九城建立永久盟约 |

乌腊于284年形成，迭嶂于289年正式订盟；412年边界协议确认祖山共同管理。

巴语诸方言和众灵祭仪构成文化联系。氏族可以吸纳婚亲、依附者和立誓加入者，并非纯粹血缘单位。

### 4. 罗勒文明

早期核心位于阿绰衡脊西麓与瑟铎台原东缘。向西人群和海岸居民融合，发展冬播、蓄水、葡萄与橄榄种植，继而经营海运。港城与台原社会很早便存在制度差异。

| 时期 | 年代 | 主要情况 |
|---|---|---|
| 西麓与海湾诸邑 | 前1400—前700年 | 山前、泉地与港口小邦并立 |
| 西岸盟邦时期 | 前700—前190年 | 港城制定海商规则，台原领主王国另行发展 |
| 罗萨特王国 | 前190—226年 | 长期统治主要港城与南部台原的大国 |
| 两国时期 | 238—251年后 | 勒汶共和国与瑟铎王国成为稳定政体 |

罗萨特继承危机引发港城拒税，238年共和联盟成立，251年停战。瑟铎保留旧王室，勒汶保留城市自治与共同文字。

勒汶家门常通过婚姻、收养与商业合伙延续。港城与瑟铎共享文化，却不采用同一种政治制度。

### 5. 族群名录与语言谱系

本节将共历742年可辨认、具有持续自称或共同体身份的本土群体登记为十八类。十八类为大陆族群统计的分类，地方支系、行业社群与境外居留者见附表，氏族与家门另列亲属关系；身份可以重叠，也不以血缘纯度判断。文明、族群、祭社与职业各有相应的成员资格。

| 群体 | 主要地区 | 语言或方言 | 身份与生活特点 |
|---|---|---|---|
| 沅稽人 | 允沅允沅京、蒲汭 | 沅稽中部语 | 平原稻作、宗族与官学；常被官书当作会稽典型 |
| 沫澥人 | 允沅沫澥 | 沫澥语 | 圩田、捕鱼与水上运输；水情知识比地亩界线更受重视 |
| 祁护人 | 允沅祁护 | 祁护语 | 杂粮、军屯、养马；村社与军户身份交叠 |
| 岑逵人 | 允沅岑逵、让陂北缘 | 岑逵语 | 林产、山道与季节工；保留较多山地祭仪 |
| 让陂人 | 让陂汇流盆地、阶地 | 让陂语 | 河田、仓储、书院；跨地区婚姻较常见 |
| 屿陀岸人 | 胥泊大陆沿岸 | 屿陀岸语 | 港城、盐业、造船；地方身份多以所属港城表达 |
| 瑙黎人 | 胥泊岛群 | 瑙黎诸方言 | 捕鱼、航行与船团；白牙渡母祀常见，但并非全体信奉 |
| 腊川人 | 乌腊乌腊城盆地 | 腊川语 | 盆地农业与城市生活；乌腊城话为其城镇通语 |
| 阿都寨人 | 乌腊阿都 | 阿都语 | 梯田、林地与寨盟；入族盟誓可以改变成员身份 |
| 喀木人 | 乌腊喀木 | 喀木语 | 矿冶聚落形成的地域群体；包含多地迁来家庭 |
| 勒贡人 | 乌腊勒贡 | 勒贡语 | 山口、驮运与关寨军役；不等于勒贡氏全部成员 |
| 阿胄牧人 | 乌腊阿胄 | 阿胄语 | 季节迁牧；聚落与路线共同构成故乡概念 |
| 迭嶂人 | 迭嶂沿瀼水诸城 | 迭嶂诸方言 | 城邦身份通常强于统一族群身份 |
| 乌笼人 | 迭嶂喀斯特山地 | 乌笼语 | 农寨、洞泉、林地；部分人同时自称迭嶂人 |
| 勒汶湾人 | 勒汶湾与赛维纳港城 | 勒汶湾语 | 城市法、海商和公民身份；外来者可逐渐融入 |
| 奥勒希人 | 勒汶奥勒希与提萨门乡村 | 奥勒希语 | 葡萄、橄榄与山前贸易；乡村礼仪较保守 |
| 瑟铎台原人 | 瑟铎瑟铎、奥斯坎及部分谷地 | 瑟铎语 | 冬播、牧马、庄园与军役传统 |
| 伊勒泉人 | 瑟铎伊勒诸泉盆地 | 伊勒泉语 | 围绕共同水源形成身份；月泉照源教流行，但分水资格不全以信仰决定 |

维瑟特矿民、纳洛伊岛民是重要地区称谓，却不另立第十九、二十族：前者包括台原人、伊勒泉人和迁来矿工，后者主要使用勒汶湾语的岛屿方言，也有其他语言居民。

会稽人、巴人、罗勒人是三文明的宽称；沅稽农户、屿陀岸盐灶户等则是主表群体中的行业与地方称谓。瑙贝氏祭系、奥瑞昂家门、胄拉氏族等亲属组织的成员关系见世家志及王统与编年志。

语言学者将现存语言分为三个主要语族。它们长期接触，共享大量祭仪与贸易借词；共同起源于阿绰衡脊活动区域，语言谱系还需要词汇和语法证据。

```text
会稽语族
├─沅稽水支：沅稽中部语、祁护语、沫澥语
├─山前河谷支：岑逵语、让陂语
└─海岸支：屿陀岸语、瑙黎诸方言

巴语族
├─盆地支：腊川语、阿都语、喀木语
├─山口高地支：勒贡语、阿胄语
└─峡地支：迭嶂诸方言、乌笼语

罗勒语族
├─西海支：勒汶湾语（包括纳洛伊岛屿方言）、奥勒希语
└─台原支：瑟铎语、伊勒泉语
```

语言亲缘研究的主要争点，是乌笼语与迭嶂诸方言的距离，以及岑逵语保留成分的来源。

稽文以字记词为主，另有记录音节的借用写法；巴文起于刻记与盟约符号，发展为音节字；罗勒文为表音字母。共用文字的地区仍有口语差异。跨文明外交依靠译官，商人可以使用一套混合交易话，却未必能读另一语族的法律文书。

云庭祭文因国家而异，不存在全大陆统一圣语。巴地盟誓保存古词，白牙渡母祀祭歌吸收海岸词，金砂和月泉仪式主要用当地语言。

### 6. 共同体成员资格与接纳程序

允沅官书爱用“稽人”概括纳税居民，沫澥船户却常先报所属堤围、船埠，再报家姓。官府要找到承担税役的人，船户要说明谁能替自己作保，两种回答各有用途。有人冬季捕鱼、春季租田，税吏把他列入农户，族谱却仍把他列在舟支。两册服务于不同的登记目的。

乌腊的“入族”也有层次。婚入者先得居住与救济，是否取得祭林采材、分田、议事或代表全族签约，须分别立誓。707年禾洛达赢得耕地使用权，并未一并取得所有成员权。喀木工人相互担保形成的炉社，又可横跨两个氏族：同一个人回寨履行祖祭，到矿镇接受炉社照护。王廷要求“一人一保”便于追税，实际生活常有多重担保。

勒汶家门的开放同样有门槛。收养有产学徒能把技艺和铺面留在门内，也可能使原有继承人失去份额。奥勒希乡村有人认可婚入媳妇管理油坊，却不让她主持家墓祭礼；港城法院往往先问产权契书是否有效。勒汶湾人因此并非天生开放，奥勒希人也并非一概拒绝外来者，判断取决于争的是收入、祭职还是公民席位。

### 7. 三处混居地的文化层次

**洑隈河镇的通航与译证制度。**船工以迭嶂方言谈险滩，仓房以让陂语报货，正式申诉多用稽文。早期商契写“货湿自认”，巴语船工常将它理解为船上一般损耗，仓主却解释成全部责任。652年的译书争议由这种差异引起，并非居民忽然发现彼此语言不同。如今契书增加宣读与译证，能减少歧义，仍须付书写费用。

**杜兰：家门、氏族与城籍并存。**阿拉赫家门的成员既有出生者，也有在驮队中被接纳的孤儿及合伙人。“阿拉赫·塞杜”中的前项表示家门归属，不可照会稽族谱倒推出一条父系血脉。城籍负责公仓负担，家门负责事故救济，山中氏族保有祭林资格。征兵时若三方都声称此人应履约，迭嶂约庭须确定何项义务先行。

**勒汶提萨门：工艺交流与地方身份。**巴地铁匠把炉祭带入瓦勒经营的工坊，奥勒希农户购买其犁头，却未因此改信百灵相认道。婚宴可能既用麦饼蘸油，又上山地熏肉；祭礼的先后顺序则会因下一代归哪一家门而起争执。物品和饮食的传播较快，继承、墓地与政治资格则由地方制度延续。

### 8. 国史叙述与地方记忆

郢承晚期的治水家传常将湖上居民写成“受教归田”，沫澥舟歌却说是船户领官军找到旧河道。两者可以分别保存一部分事实：官府提供持续征工，船户提供水情知识；争执发生在后来谁能把贡献换成堤权。

赫腊王史把乌腊阿义写成“开炉定盟”之王，喀谷家账则把军队获得盐粮写成商队垫付。乌腊的胜利需要粮田、矿主与运路人的合作，但开国后，并非所有协作者都获得相同地位。背夫承担运输劳务，但较少留下家账。

勒汶共和誓词强调港城共同争取自由，瑟铎的授尺史诗强调王室守住台原。两者均较少讲226—251年在敌方境内的混居家庭。港城出身者仍可给瑟铎军队修车，台原粮商亦可给共和舰队卖麦。三文明的界线适合研究长期语言与制度传统，战争中实际的合作界线常沿粮路、信用与地方安全重新组合。

### 支系、语言接触与姓名的演变

十八群体下的地方自称至少有以下持续支系：沅稽的鳣陂城、京南；沫澥的芦荡舟支、围田支；祁护的屯田、丘牧；东麓的林保、驮路；让陂的上阶、汇流；屿陀岸的盐湾、船坊；瑙黎的内列、外礁；腊川的城田、河畴；阿都的栗寨、阿都溪；喀木的炉社、旧井；勒贡的关寨、谷驮；阿胄的东坡、西坡；迭嶂的干流、支谷；乌笼的洞泉、梯田；勒汶湾人的湾港、岛港；奥勒希的园作、山前；台原的王田、庄园、牧路；泉地的上泉、渠尾。这些支系依地方聚落、生产和生活组织形成。支系内部有人改业或迁居，名字仍可保留。

语言互通取决于听者经历。沅稽中部语与祁护语日常可经适应交流，沫澥语在船具、水位词上差异大；屿陀岸语与瑙黎方言通常需要重复和解释，外礁最难。腊川与喀木贸易话较近，阿都、勒贡可部分互懂，阿胄史歌与盟誓对城里人常需译解。迭嶂城际通语掺腊川、让陂语词，乌笼语正式证词仍需独立译证。勒汶湾语与奥勒希语可互通，瑟铎与泉地在读写共享字母时仍有读音和水权词差异。跨三个语族须借助译证或学习。

稽文常用字约三千，官学长文需更广字库；巴文有八十二个基础音节符及复合补记，记录不在旧音系中的名字时加点记辅音；罗勒文二十六个字母，泉地保留两个复字用于本地音。数字使用各自字形，商账中的银衡数字在本书采用十进位数字转写，但世界内的数字符号称商数，不认定由现实文明输入。阿绰祖山碑以三种现行文字并列记述共同祭仪。

会稽单姓、双名渐从地名和职称中独立；同姓胥氏造纸支与岑逵胥姓关吏未必同宗。巴地双音氏族名可由盟誓接纳取得，记录相应成员资格。迭嶂仅岩泷、郦迦两城保留与本城古地号同根的族姓；雾珀、桑索、斐陵和卓各由药采担保、织索行业、旧军爵冠音及迁田户名发展，索藤与弥另有行业和田契传统，详见方域志；苏梅娅·达梅为个人名加母名，下一代不必沿用母名达梅。勒汶家门名可由收养与合伙继承，瑟铎贵族冠名也能由合法承嗣延续。姓名变化随各地官文、迁居和承嗣逐渐发生。

在742年法定登记中，人可以同时声明本地籍、使用语言与祭社，人口表的十八类按主要自称取一项，以避免重复计数。文明归属是长期语言、制度和记忆的分析单位，居民往往根据婚姻、岗位与诉讼场合选用不同身份。

### 归纳与评价

十八主要群体有内部支系，共享文明不保证语言完全互通。婚姻、入族、收养与迁居创造多重身份，姓名和文字的演变也使古老地缘关系逐渐脱离字面；文化复杂性来自可追踪的制度和生活过程。
