## 一、名称怎样留住地方历史

地名可以先指一片田、一处泊地或一段担保道路，后来才借作城市和国家的称号。现行政区的成立日期，并不就是地名诞生的日期。湖上人以水位和船埠认识地方，王廷用田籍和征役范围认识地方，同一片土地因而会留下不止一个名字。本志以现行通称定位，旧名用于查阅旧案、辨认地方口述；异名相近须核地点和年代，不能据读音合并两处聚落。

阿绰是山地旧祭语中“彼此相认的高处”，起初沿山口季节集会传递。平原商人称连续山岭为衡脊，祭者又以云停峰顶的意象解释云根。阿绰祖山在412年取得共同管理的明确范围，旧祭名却不止始于这一年。峰顶、古祭道与约定祭所属于共同管理地，邻近山麓的田土、寨籍和商路另有管辖。山名的共同性与祖山行政的有限性，应当一起说明。

沅稽水中的沅承贯田水旧音，稽为河邑祭名；瀼水以会水词让的旧借字定河名，不把一国疆界等同整条水系。腊川取盆地供粮盟乌拉的短音，西段进入勒汶辖境后仍沿用旧河名。沫芦水与澥口渠分别记入湖来水和人工排水；水、溪、川与渠的通名说明水道性质，不能根据题名授予跨境征税或截水权。

## 二、七国各有自己的命名层次

允沅以古稽水籍、仓邑祭辞和湖上口语为底层。伊允的会仓词与主河沅音进入王廷称号，318年重建朝廷后用于国号；京是王都通名。蒲若在田籍定写蒲汭，原指芦根旁的河湾田地。莫澥是湖上人称涨水相连浅湖的词，官书写作沫澥。大决后的分堤册使湖名稳定进入郡籍，却没有消除船户按船埠报籍的习惯。

让陂保留山前河谷和庄契的旧音。让陂意为会水低地，旧抄本借瀼字记首音；323—327年守仓与拥立之后，仓邑名扩为国家称号。洛原原指叠起田坎，写作泺垣以后，又兼指庄园土垣。洑隈来自舟人所说回弯里可停船的水面，接峡是仓商按换载用途取的外称。652—657年译书争议使两套称呼都进入宣读证词，正确译名须同时说明契约责任。

胥泊以岸语泊地、船坊俗称和岛语祭歌并存。胥薄原指潮里可系舟的内泊，港账后写胥泊；346年海防王室成立时借港名为国号。曼鲁的鹭聚沙脊义由盐簿定写芒鹭。瑙利在母系祭歌中指逐礁相连的泊处，岸上官文写作瑙黎。岛群古称早于424年特许，府、港城和岛区的权利不能因共享同一岛名而合并。

乌腊多用寨盟双音词、炉坡工地号和护送范围名。乌拉是谷口诸田相互担保的古盟音，王家与粮邑逐渐定写乌腊。阿度的梯级田土义进入阿都寨盟名；卡木从炉坡风口的工地称谓发展为喀木。勒空指道路担保所及之处，誓书写作勒贡。519—523年撤军裁断沿用旧地域词，是为了辨清役期和承诺，并非宣布冠名家族所有道路都归王廷。

迭嶂不把九城整齐编成一套地景名。岩泷从岩壁出口旧语而来，索沱承纤工系索落水的呼滩词，弥洄先是回湾粮田名。乌笼保留洞泉湿气的地方词，台毗指石台旁可下种的土。杜兰的停驮换舟词随跨山商队传入，裴戍则承迁来军户分段守路的旧营称。共同议席以九城为成员，不要求各城语言、姓氏和祭礼同源。

勒汶以西海字母记录和港市短称为主。勒温原是内湾平岸诸邑的名字，末音在贸易话中弱读，238年城市盟誓采用勒汶称共同政体。赛维纳保留白亮石岬的航图词，奥利希的朝海风低坡义在庄契定写奥勒希。纳洛伊是灯火相望的一串岸，岛章保存完整长音。罗勒仍指文明及其文字传统，勒汶则指共和国，不能用一国新名消去同文明台原社会的历史。

瑟铎保存王台古语、贵族冠名和泉地复字。瑟铎原指立誓授印的高台，226—251年王统保存后取得国号含义。梅里安是谷风可达的长田，维瑟特是破开的红石岸，名称分别进入谷地和海港契书。伊萨尔的“把尺交到手中”义保留祭院仪式；伊勒的“轮到水”义来自守泉水次。庙领地界、泉份和庄园田界并不因语词联系而成为同一范围。

## 三、通名与法律层级

| 通名 | 本卷所指 |
|---|---|
| 郡 | 允沅二级行政单位，郡守由中央任命，县案分级复核；地方堤围按受益关系另行记账 |
| 府 | 让陂与胥泊二级单位；前者府正须中央和议政院认可，后者府督协调海防、海关及跨港事务 |
| 领、边领 | 乌腊或瑟铎二级单位，直辖、盟约、贵族及王领的权限来源分别查明，领字不表示一律世袭 |
| 神庙领 | 瑟铎二级特许属地，常规租税及一般司法依约；外交、铸币、叛乱和重大刑罚复核仍归国家 |
| 城邦、岛盟 | 迭嶂九城及勒汶成员的二级辖区，包含治所和乡村；成员代表资格与居民票权分别办理 |
| 县、城县、盐县 | 重点三级行政单位，分别按本国县制、王法及盐灶登记办理；行业名不自动给予独立税权 |
| 河镇、城镇、港城 | 重点三级聚落单位；港城有原章特许，河镇和庙城镇不得仅凭名称取得相同自治权 |
| 港区、岛区、矿区、泉区、寨区等 | 本卷重点三级类型，只在原志明定事项上行使地方权限；不能从区字推成独立政体 |
| 城、堡、关、埠、寨、院 | 聚落或设施通名，可作治所，但本身不表示统一行政等级 |
| 村、坊、保、水社 | 三级单位内的登记与协作组织，分别承担田簿、工役、担保或分水义务，不重复计为二级区 |

山系、岭、谷、盆地、湾、礁、群岛、河、水、溪和海域属于自然通名。人工渠应与天然河区分。自然名称可以借入行政称号，借名不等于取得全部水土权。派和集团多是本卷对合作网络的简称；行会另有会章，掌资格、买卖、互助及有限罚则，不能把财政派的意见写成一项行政命令。

## 四、旧新名检索与旧国分期

| 旧称 | 本志通称 | 使用时的辨别 |
|---|---|---|
| 越宁、澄川、临海 | 允沅、让陂、胥泊 | 国家简称；涉及湖、河、都城时查相应具体名称 |
| 巴梁、玄峡 | 乌腊、迭嶂 | 两个现政体；巴仍为文明名，九城仍分别保有城籍 |
| 罗勒共和国、萨汀 | 勒汶共和国、瑟铎 | 罗勒文明、罗勒文和罗勒语族保留 |
| 稽京、澄都、潮安 | 允沅京、让陂城、胥泊城 | 治所名，不是完整郡府辖境 |
| 镜泽、白岭、外海列岛 | 沫澥、勒贡、纳洛伊列岛 | 分别识别湖区、护路地域和岛群，行政简称另查方域志 |
| 古稽王国、大宁王朝 | 沅稽旧国、郢承王朝 | 前者为残缺铭名王表所记旧国，后者为前280年建立的王朝 |
| 古巴王国、衡梁王国 | 巴川旧庭、赫腊王国 | 诸王系统合与后来开国重盟是不同阶段 |
| 洛萨王国 | 罗萨特王国 | 台原军盟及港城特许的旧统合政权，不改称文明罗勒 |

沅稽旧国中的稽是河邑祭名，旧国是后世分期用语。郢承以王家冠名配承受水工征役的王廷宣言，大宁则是强调旧疆广阔的史书称号。巴川旧庭保留文明自称巴，但庭指统合征役与盟誓的王廷，不能据此把前900—前360年数个王系编成一条父子链。赫腊承开国王号短音与盆地古盟词；罗萨特的尾音为契书统合标记，港账省写洛萨。旧国分裂后的继承主张属于政治选择，不由字形相似自动成立。

## 五、家门、宗教与作品的异名

郢氏京廷与让陂南支同宗，国号分开不意味着另造祖先。申莘氏官学网络与沽氏湖田网络通过婚姻相接，家名不能把清丈与堤费争论分成两个互不往来的血族。造纸胥姓与山路胥姓是否同宗尚无明证，官文同字不足以补谱。

乌腊氏族冠名可以随入盟接纳取得，巴语个人名不按一套固定辈字循环。迭嶂只在岩泷与郦迦保留同城根族姓。雾珀取药采担保旧音雾泊，桑索取织带制绳行业冠称，斐陵承旧军爵冠音斐林，卓承迁田户旧名卓伊；四姓不因移居乌笼、台毗或裴戍而改从城名。索藤另由纤运称谓发展为家姓。苏梅娅·达梅为本人名加母名；阿拉赫·塞杜为家门名加个人名，两种格式不可互换。喀石家个人名与阿拉赫家门近音，也不证明亲缘。

西海家门可因收养和合伙延续。672—678年塞莱俄家收养铁匠学徒，法院承认铺面继业，家门另议墓祭，公民籍仍须申请。瑟铎奥瑞昂家门的祖父、庙产管理人和大司祭分别记谱；冠名延续不使最高祭职依法世袭。瑙贝祭系以母系资格、学习及岛议认可继任，也不同于普通港籍和婚产继承。

云衡礼教、百灵相认道、白牙渡母祀、金砂初脉教及月泉照源教保存共同意象，却有各自礼官、祭歌和巡井水次传统。教、道、祀是官书归类通名；424、462、538年的特许确认晚于礼式形成。云、鲨、虎、金砂与月的名号不能用作扩大庙产、船事或分水权限的理由。

书题也留下使用者的选择。《澥灯夜问》旧题《泽灯问堤》，母女查险与收费质问在舟歌、刻本和资助本中有不同侧重。《索沱桥证》保存工签与补偿证词，《索沱桥下簿》却将多年诉讼压成戏剧庭审。《伊勒渠的双月》在庄园宴会和清渠夜有不同删节。检索旧题必须核体裁与版本，文学场面不替代县案、量器、观象或收据。

## 主要人物姓名选释

本节选取现任国家主要负责人、开国者及贯穿重要争议的人物，解释其家号、个人名或后世称号；旧称与本志通称的对应另见名称索引。

| 人物 | 称名及其来历 |
|---|---|
| 郢景晏 | 郢是王家谱姓；景为本支沿用的辈字，晏取安宁之愿。名字形成于登位以前，不能把后来求稳的施政直接当作取名原因。 |
| 郢绍元 | 让陂支保留郢姓，与允沅京廷同宗；绍元取接续家祀、重立家业之义。绍是名的一部分，并非他在另一王廷之下承受册封的标记。 |
| 邗明澄 | 邗姓承海防家门旧音，官文以单字定写。明澄是岸上书面祝名，兼有灯火可辨、泊水清定的愿望；王室采用文辞名，未使普通船户的乳名、母名消失。 |
| 乌腊都拉 | 乌腊是入盟王家的冠称，都拉为巴川口语中“同担一端”的人名，意象来自两人抬负。王室与普通寨户都可使用这个祝名，名字本身不授盟主资格。 |
| 弥允修 | 弥家保留迁田户旧姓，允修是入城后采用的书面名，取守信修业之意。弥姓与弥洄城首字相同，却不能据此认定家门为该城的始建者。 |
| 维鲁恩·吕安诺 | 维鲁恩是家门名，源于西海契语的“代言之屋”；吕安诺是个人名，保存旧港语“晨启”的词根。前者因担保与辩讼成了家号，后者只是家中所取的祝名，两者都早于此次执政。 |
| 莫拉提·蒂维诺 | 莫拉提原是港市所称的共同寄存房，合伙支系沿用为家名；蒂维诺取西海语“安归”的人名旧式。称名习惯出于海行家庭的期望，不能据字源断言本人从事过远航。 |
| 瓦勒·瑟蕾 | 瓦勒来自家谱中沿袭的旧岸称，瑟蕾是旧语“明亮”的个人名。瑟蕾并非女性专用名；本地按家册和本人称谓辨身份，不靠译名尾音判定性别或任职资格。 |
| 萨维铎·艾德尔岚 | 萨维铎承旧王室冠名，早期含护持誓台之义；艾德尔岚将王台语“坚存”与“枝嗣”的旧词根合为祝名。国号瑟铎与王家共享誓台传统，却不是直接拿今王姓名命名国家。 |
| 郢承文 | 承文是宗室书面名，取承习礼文之意。后来拥立者用此名称颂恢复文治，是事后解释；他获得王位仍须由继统战争、军粮与宗室关系说明。 |
| 郢开渠 | 开渠属于功业称名，王统采用的是后世通行称号，并非有证据可考的幼名。称号保存其整合水役的政治记忆，也容易遮蔽原有渠户和地方首领的贡献。 |
| 乌腊阿义 | 阿义是巴川古盟语中的“可作互保者”，旧外译曾作赫山。乌腊冠称取自其后来联合的王家盟名；叙述开国以前事迹时，这个全称带有后世追称的成分。 |
| 申莘原 | 申莘为复姓，来自官学家门沿用的双音旧号；原是个人单名，取根本与端始之义。写作单名不表示寒素，复姓也不自动证明掌握官学职位。 |
| 杜汀娘 | 杜是户籍姓，汀是湖上临水地称，娘为乡里惯用称尾。诉讼沿用她本人和邻户常说的名字，未将其改写成士人式双名；由此可见妇户进入案册时仍能保留地方称名。 |

## 六、归纳与评价

衡岑名称的层次来自迁居、交易、祭仪、官文定字和制度承接，既有可释词义，也有只保存读音的古名。旧称可以帮助核证，但不能为缺失的谱系和建置补出确定年月。读地名时先认专名，再认通名，最后核地点、年代和权限；这样才能看见名称怎样保存地方生活，又怎样被后来政权与编者重新组织。
