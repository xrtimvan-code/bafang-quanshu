# 总论 · 衡岑大陆

> 《弥洛洲志》第一卷。记述时点：共历742年秋。

[返回志纲与总目](../../00·志纲与总目.md)

### 1. 弥洛洲的三大陆

衡岑大陆属于**弥洛洲**。弥洛洲共有三片大陆，衡岑是其中尺寸偏小、与另外两片大陆距离略远的一片。衡岑与两者往来较少；另外两片大陆之间的交流则更紧密。

《弥洛洲志》分为三卷：第一卷记衡岑，第二卷记乌弥尔，第三卷记萨阑。乌弥尔有十二国，萨阑有十国，两者隔两门海联系较紧密。乌弥尔有瓜凉、芦赫、大元溪三个独立文明，萨阑有卡兹帕、摩揭始罗、化玻、鹿野四个独立文明；霄安、七斗两个文明跨越两大陆。详见[全书志纲](../../00·志纲与总目.md)。

衡岑与其他大陆的距离较远，交通班次和交流频率较低，因而保有较强的区域独立性。海外贸易以胥泊—乌弥尔西北航路为主，距远量小；勒汶亦有零星远航，具体货品与费用见经济与赋役志。乌弥尔与萨阑曾受跨大陆承曜王朝部分统治；该朝已分裂，衡岑未被其征服。阿绰衡脊起源是衡岑三文明的形成背景，其他九文明有各自的源流。

弥洛洲的“西湾”为洲名。三大陆的方位为：衡岑居西北，乌弥尔在其东南，萨阑在乌弥尔东面偏南；两门海位于后两大陆之间。

### 2. 大陆名称与时代

大陆通称**衡岑**。“岑”指山岭，“衡”指横贯中部的阿绰衡脊山系。三种文明各有古称，衡岑之名近三百年来通行于地图与外交文书。

本卷记述的当下为共历742年秋。共历以《三水通商约》签订年为元年，各国仍另用王朝或地方纪年。

技术总体处于成熟的前工业时代。铁器、纸张、印刷和水力机械已广泛应用，沿岸帆航成熟，远洋帆船集中于少数大港与专业船队；火药用于攻城、矿业及少量舰炮、要塞炮，尚未取代传统武器。宗教对社会影响深厚，但没有得到证实的超自然力量。

### 3. 记述原则

衡岑有三文明、五宗教、七国，地理上分为八大单元，气候按三个宏观类型讨论。各文明由多种地域群体融合形成，居民的宗教身份常有交叠。

宗教起源叙事与实际人口迁徙分别记载。制度规定与现实运作分别说明。派系指政策、家族、利益及任命关系集团，不指现代政党。

行政层级统一按国家为一级、直属地方区为二级、基层区为三级记述。允沅之道为跨郡巡察协调区，不列为独立行政层级。

### 史料来源与记述方法

本卷涉及的书籍、账簿、碑刻、口述和引文属于本书架空历史的文献体系。各材料的成书年代、传承和立场列于下表；引文用通行语译写。叙事复原依据可记录的行动与程序，材料分析则结合其保存范围和编纂目的。

| 简称 | 材料及传承 | 能说明什么，不能说明什么 |
|---|---|---|
| 堤册 | 《沫澥分堤册》：181年官署条目，现存294年抄本，含若干后补田名 | 可对照工程与摊费；漏记无籍船户，不能当灾民完整名录 |
| 仓记 | 《瀼仓守门记》：禄氏家塾352年编，收323—327年仓签与家传 | 粮仓组织较可信；把封仓叙成仁政，有意淡化饥民与敌军损失 |
| 峡约 | 《岩泷盟约诸本》：289年旧条、412年界约与606年复议分层保存 | 可见盟权变化；部分所谓“开盟旧例”实际是后加解释 |
| 舟歌 | 《瑙牙四季祭歌》：祭师贝听汐于602年整理，更早部分仅有口传 | 保存岛民的失船记忆；不能据歌词推出424年确切舰数 |
| 炉簿 | 《砾托尔封井簿》：455—462年轮班、停井及赎工记录，后由矿契庭归档 | 记录生产中断与赔付；把离矿者记成“走工”，常省略他们离开的原因 |
| 泉刻 | 伊勒泉旧渠石刻与《伊勒水次簿》：538年起多次重刻，保存按季分水抄件 | 水次有连续性；石上先刻的名字并不总是最早居住者 |
| 海账 | 《勒汶公账复核录》：583年调查选录及勒汶公账署附表 | 可检验债务与采购关系；只收被调查项目，不能代表全部贸易 |
| 桥证 | 《弥洄桥工证词》：618—620年迭嶂约庭证词抄录 | 有劳工、包工者与寡妇的陈述；证词受提问方式、译写与赔偿诉求影响 |
| 校议 | 《洑隈译书学舍议录》：652—657年地方会议与学生契书 | 可看不同语言的制度地位；识字家庭比无籍居民留下更多文字 |
| 港录 | 《胥泊征船复核录》：729年鹭汐号案及后续偿付登记 | 船型、用途、受偿者可互证；失踪而无家属申报的船工可能未被列入 |

材料的独立性取决于传承关系。禄氏家传被三家书院抄录，仍只算同一传承；官署据税册编国史，两者共享人口资料。账簿、工程遗迹与相对独立的地方叙述相合时，本卷才提高判断的把握。传说与剧本主要证明后人怎样记忆过去。

伤亡、户数和兵力依登记覆盖采用数值、范围或趋势，记录不足处标为“不详”。早期文明的形成过程延续数百年，各地发展有所重叠，分期表依可辨识的政治组织划分阶段。

制度条文规定居民可以主张的权利，案件与账目反映这些权利的实际执行。某一事件的政治背景、家庭影响和地方条件，分别见历史志、民生志及方域志相应条目。

### 归纳与评价

三文明与共同祖山构成联系，七国分治则使同源传统分化。全卷以同一时点、度量对照和史料层次串联：山川、区划与制度构成比较基础，史料的异文和估计误差另作说明。
