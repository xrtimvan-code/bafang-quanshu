# 山川岛屿考：三陆图文对读

本篇与第五版图册配合使用。按主要地理单元、图示岛群和全部双边陆界分别说明地貌、水文及历史关系。岛群编号对应自然地理图上的“岛1、岛2”等标记；编号只在各陆内部使用。小附岛按所属地形群合述，不将每个礁石另造为一处火山。

本书采用与地球相近的水循环和侵蚀过程。海侵分割旧丘、河流冲积、沿岸搬沙和基岩差异侵蚀是不同机制；政治辖界另由聚落、契约和统治沿革解释。以下地质解释属于本世界的编定设定，年代未作岩层定年的部分不填确切年数。

## 岛屿淡水的共同条件

大岛的季节短水以蓝色细虚线表示；低沙洲、裸礁和多数小岛不画独立大河。雨水入渗可以形成地下淡水，储量受面积、岩层、降雨及海水侵入影响；图上的井田叙述不保证每口井全年同量出水。较大的岩岛有局部丘脊，低沙附岛用低地色表示。

## 衡岑

### 主要地理单元

| 单元 | 地势与水文依据 | 文明与历史关系 |
|---|---|---|
| 沅稽大平原 | 主河冲积面、侧方湖洼与北部侵蚀缓丘相接；堤后低地不能与较高河阶同色抹平。 | 会稽水籍、174—184年水灾病患、734—736年灾册复核。 |
| 胥溟海岸带 | 胥泊河口为泥沙低岸；屿陀一侧保留硬岩岬湾。大港、盐场和河口驳运各占不同岸段。 | 港口专业分工与胥泊海关；大陆三角洲与瑙黎岸岛分别登记。 |
| 让陂河谷 | 瀼水出山后展开河阶，再入沅稽水；仓埠近水，旧居和书院多择较高地。 | 323—327年守仓、628年航段约；换载收入与田粮供给相连。 |
| 阿绰衡脊山系 | 北段高、南段破碎；东西支谷之间有主脊，中段有低鞍口。祖山处于支脉，非全陆唯一河源。 | 三文明早期山地交往、412年祭地共管、709—713年越冬借牧。 |
| 腊川盆地 | 低平盆底接阿都丘陵与喀木台地，西向出口通勒汶。矿丘、炭林与粮田具有高差。 | 前372—前360年争炉、512—517年炭林停炉；巴文明的盆地与矿谷交换。 |
| 迭嶂山地 | 深切曲谷、局部小盆地及台毗高地并存；乌笼的可溶岩带供洞泉，其他岩峡不一概属岩溶。 | 271—289年解贡、618—620年桥工罢役、733年封纤案。 |
| 勒汶西海沿岸 | 基岩湾、局部平岸与低丘组成狭长腹地；腊川出口切穿山前丘带，外岸散布旧陆残岛。 | 罗勒港湾社会、398—403年岛盟代表权运动；粮食与船货往返山前。 |
| 瑟铎台原 | 缓起伏高平原被浅谷切开，泉水沿透水层底界或裂隙出露；季河依冬雨来水。 | 538年分水章程、694年领界约、740—741年旱情；庄契与水份分记。 |

|---|---|---|---|
| 岛1 · 纳洛伊列岛 | 海侵淹没旧丘间鞍部，较硬脊段保留为长短不一的岛。主岛有两侧短谷，小岛主要露岩。 | 雨季谷水、坡脚井与雨池并用，灯标小岛需运水；旱季限制客船取水。 | 勒汶岛盟以领航、补水和灯标负担争取代表，398—403年运动与岛户劳动有关。 |
| 岛2 · 纳洛伊近岸附岛 | 西岸散布的岩岛、岬尾与被水道切断的丘段，间距随旧谷而变；不是一道连续堤岸。 | 较大附岛有季节沟，小块裸岩无稳定泉；不接腊川干流。 | 沿岸渔聚和近海灯标依大陆港口供应，不另造一个远洋王国。 |
| 岛3 · 瑙黎群岛 | 陆缘旧丘被海水分割，主岛保留偏心长脊、谷口低地和曲折泊湾。 | 岛内短流分赴本岛两岸；较大谷地可有井田，干季仍需蓄水。 | 胥泊的近岸航路、渔场与瑙黎祭歌在岛间延伸；大陆三角洲另在主河河口。 |
| 岛4 · 瑙牙外礁与南部附岛 | 基岩外礁、低沙岸与局部暖浅海礁并存，主岩岛的丘脊不因祭名而改变外形。 | 岩岛以小汇水谷和雨储为主；低沙洲淡水脆弱，不能普设常流河。 | 瑙牙祭地、海关与渔聚分工；鲨牙祭环解释名称，不是地质成因。 |

### 双边陆界及形成依据

| 接壤国家 | 所经地势 | 历史形成和跨境权利 |
|---|---|---|
| 勒汶共和国—瑟铎王国 | 海岸丘陵与台原浅谷过渡 | 港城腹地和南方庄领的旧辖界在谷口衔接，通岸道路跨境；不沿全段河心。 |
| 勒汶共和国—乌腊王国 | 腊川出口及山前丘带 | 乌腊盆地与勒汶下河港市分辖，河流横穿两国；提萨门换载、谷路担保与国界分别计算。 |
| 瑟铎王国—乌腊王国 | 喀木台地南缘与台原北坡 | 冶炉粮路、炭林与牧地沿旧领契分界，矿契可能越行政线，不据此另添国土。 |
| 瑟铎王国—迭嶂盟国 | 台原东缘与瀼水源地邻坡 | 山口、牧路和谷寨范围拼接边线；瀼水流域边缘与王领外界只部分重合。 |
| 乌腊王国—迭嶂盟国 | 中央南段支岭及峡谷上口 | 盆地王属与九城谷寨长期分治，412年祖山共管不消除一般边境。 |
| 乌腊王国—让陂国 | 祖山以东山道与出山支谷 | 过山货路在让陂一侧接仓埠；边界依寨属、山脊和旧验路地衔接，不封闭整条商路。 |
| 乌腊王国—允沅王朝 | 阿胄东缘—岑逵西北分水脊 | 两侧分别纳入乌腊牧地和允沅山麓郡；直接山界存在，常用路仍绕低鞍口。 |
| 迭嶂盟国—让陂国 | 瀼水出山峡口和河阶 | 上段城寨与下段仓运国分辖，628年航段约规范通运，河上费用不等于每转一湾都过国界。 |
| 让陂国—允沅王朝 | 山前河阶与汇流粮田 | 郢承分立后仓城、村籍与旧郡界分属两国，平原上保留田契折线。 |
| 让陂国—胥泊国 | 下河丘湾与近海低地 | 让陂仓运腹地与胥泊港务腹地相接，山前路、盐运与河口货路分担不同税役。 |
| 允沅王朝—胥泊国 | 内陆粮田、湖区与近海丘带 | 郢承分立后的郡府与港关边界沿村籍、旧堤和丘线形成；沅稽水跨境入海，不全作国界。 |

表列是双边边界组合数，不是界桩或曲线段数。湖岸、河谷及旧省界可在一组边界中交替出现。海上航线、渔场轮用、宗庙私产和季节牧路分别说明，不把它们补画成陆界。

## 乌弥尔

### 主要地理单元

| 单元 | 地势与水文依据 | 文明与历史关系 |
|---|---|---|
| 哈岚山弧 | 抬升山地被长谷切开，西侧较湿、部分东坡有雨影；山前含盐沉积层形成盐台与井区。 | 瓜凉的谷牧盐粮交换，487年震损盐井及山口修护。 |
| 五井北原 | 高坪、冬草洼地与麓泉灌谷相间；泉河来自山地，草原不是均质无水平面。 | 牧营按冬草、井路与谷田组织，旗界和季节使用权各有范围。 |
| 承渠扇地 | 山口冲积扇、旧河阶及内湖低地相连；高田须按实际水头受水，末渠有断流和盐化风险。 | 159年迁村、611—614年高渠债争、688年末圩减役。 |
| 槐脊分水岭 | 老隆起剥蚀成较低林岭，西支分开承渠闭流地与赫恩湖水系，东坡供渊流上游。 | 索河—石楗隘路与辕渡—瞻水缓丘是不同通路，旧朝三水转运并非天然一河。 |
| 赫恩湖盆地 | 洛恩河进入低盆，较高湖台适合常住，浅湾与洲田随湖位转换；西南低岸有外流出口，湖体另向南伸出浅湾。 | 芦赫沿湖聚落、鱼田季用与城堤传统；与承渠内湖分属不同水系。 |
| 洛恩河下游 | 坡缓多沙，旧槽、现槽、天然堤与潮汊交错；稳定分汊位于出湖后的低地。 | 635年变槽、638年战争、641年异槽疏河约；国界没有随新河自动迁移。 |
| 西南砾湾 | 硬岩伸岬，较软岩层退成湾；坡园排水好，染草洼地较湿，港边崖岸另具岸坡条件。 | 凯兰园主、苏迈港务和乡村用水利益交叠；碧汀仍在大陆。 |
| 渊流多汊平原 | 上游支水汇合，下游洲田、堤后洼地与人工支渠展开，东淖才形成入海三角洲。 | 大元溪共同渠务、638年迁祭轮、733年共尺与734年洪水。 |
| 桑南台地 | 较早冲积面抬升并被小谷切开；桑棉与旱粮多在台面，稻田靠谷底及台下受水地。 | 509年城乡联合、612—618年学田争议、701年谷吹换工。 |
| 两门陆岸 | 北中段为岬湾短河，南段盐岸和三角洲低平；雾雨、台地粮路与风暴风险同时存在。 | 霄安跨海税港、706—709年检疫及739年救船；济众和东淖留在大陆。 |
| 北候岸岛 | 长汛是大陆岸台，其外为海侵岩岛、浅沚与礁道。大岛短谷和小岛雨池承担不同补给。 | 531年护航联约兼有岸农、渔户和远航船户；深港并非海盟唯一基础。 |

### 图示岛群

| 图号与岛群 | 成因及地势 | 淡水与居住条件 | 历史及辖属关系 |
|---|---|---|---|
| 岛1 · 结帆主港岛 | 较宽旧丘段被海侵切断，偏心丘脊使深湾与较低田谷分处两侧。 | 雨水补给短溪和浅层地下水，枯季共井及雨池承担船用补水。 | 结帆主港的远航仓与地方井田并存，海盟召集不等于王家独占岛井。 |

| 岛3 · 两炬岬岛群 | 陆架残脊两端成岬，中间有较低鞍地和泊湾，附岛沿淹没谷两侧分布。 | 主岛两侧短谷各自入海，航标高岸与取水谷并非一处。 | 两处航标得名两炬；救船判例按人命、绳材与风险分别计费。 |

| 岛5 · 银翎岛群 | 长岛的丘脊沿旧岩体方向延伸，侧谷与鸟崖共同造成不对称岸形。 | 湿季短流分向两岸；井田较集中的谷口保留粮水仓。 | 北候外航与鸟崖采集各有季节，远岛船班承担补给责任。 |
| 岛6 · 玄帆岛群 | 老丘被海蚀成一长岬与若干侧湾，较软谷地退为修帆泊岸。 | 短沟径流和雨储维持小谷聚落，干季补水由船班约定。 | 玄帆航域的船材、修帆与避风服务，和大陆染草产地分别计账。 |
| 岛7 · 遥铃礁群 | 远南岩礁、较低岩岛与浅沙段相间，地势不足以支持一列高山。 | 小岩岛可设雨池及有限浅井，外礁站须定期运水，不承诺所有礁皆可住。 | 海救站与过航警示形成航域责任，礁名不是田地面积。 |
| 岛8 · 外礁港附岛 | 西南岸外侵蚀残丘，与外礁港的大陆岬湾同属岸缘系统。 | 谷沟短小，居民兼用雨池和大陆运水。 | 附岛服务近岸引航；苏迈外礁港的主市、下河货路仍在大陆。 |
| 岛9 · 玄帆外丘岛群 | 海侵分开的低丘和支谷，与玄帆主岛同属陆架旧岩地形。 | 大岩岛保留短汇水谷，小附岛雨储为主，分别画丘脊和低岸。 | 属玄帆航域；旧图误绑凯兰碧汀洼地，已按地理关系订正。 |
| 岛10 · 遥铃南段补水岛群 | 老岩岛旁有低沙洲；主岛有岩骨和丘谷，附沙洲随岸流变化。 | 主岩岛的井与雨池可供中继补水，沙洲只作临时泊处。 | 合隶遥铃航域；东淖三角洲及渊流河口始终在大陆。 |
| 岛11 · 遥铃北段中继岛群 | 陆架残丘与岩礁构成北段中继泊地，岛形沿旧谷和岩脊展开。 | 可居丘岛有短沟，露礁无常住水源；海救粮水按航季储备。 | 与遥铃南段分担船班，济众大陆盐岸的盐田和税署没有移岛。 |

## 史地解释的限度

自然条件影响聚落密度、供给路线和作战季节，历史结果还取决于人群组织和制度选择。腊川的矿丘与粮盆支持联盟，也可被分别控制；同一湖区可以维持共同捕鱼，也会出现排他的围田。跨境河流使合作成为现实需要，却不保证各国总能及时分水或赔偿。

现政区图统一记742年秋。二级区细界仍按方域志的村籍、渠役、港务和旧领界对读，地理单元不是另一套行政区。岛群成因可以合述，居民使用权却不能因成因相同而归为同一国家。

## 归纳与评价

三陆地理以山脊、盆地出口、连续谷地和河口为骨架。海侵岸岛、低沙洲和大陆三角洲在图上各有位置；国境既循山水，也沿旧籍旧契。地图与叙述必须共同说明这些差别，表列数量齐全只是检查的一部分。
