# 弥洛洲志图册绘制规范

版次：第一版。制定日期：2026年10月15日。适用对象：弥洛洲总图、衡岑、乌弥尔、萨阑三陆地图及后续专题图。现行名称已统一，旧版对应西湾盛洲、岚衡、洄原、燧岬。

## 一、参照与用途

本规范以国内《国家基本比例尺地图图式》GB/T 20257.4—2017为图式参照，借鉴分类表示水系、地貌、居民地、交通、境界和注记的编图思路；方向、比例尺和图例的基本要求参照《国家版图知识读本》的地图教育说明。以下颜色、符号、取舍和检查程序是为本书自定的规则，不宣称本书地图具有国标地形图的测绘精度。

地图首先服务于阅读历史：使读者能辨认居民为何在此聚集、商路为何经此、国家为何在此形成，以及洪水、旱灾、改道和战争怎样改变地方生活。艺术底画可以辅助表现，最终显示的山河、行政边界和名称须依书中设定绘制。

本书世界按与地球相近的重力、水循环、岩石侵蚀与气候过程设计。地形成因属于新补的世界设定；尚无证据确定的地质年代和板块名称不强行填写。

## 二、每张正式地图必须具备的要素

| 要素 | 必须表达的内容 | 绘制要求 |
|---|---|---|
| 图名 | 地域及主题 | 写明总图、地形与政区图或历史专题图，不只写一个大陆名 |
| 时间 | 政区与居民地的记述基准 | 现行政区统一标“共历742年秋”；历史图另写具体时期 |
| 方位 | 北向及大陆间相对位置 | 默认北在上，设清楚指北标；旋转插图另标方向 |
| 距离参考 | 地域大小与主要交通距离 | 关系图标明示意；可用大陆宽度、主要港路距离帮助判断。只有位置经过统一尺度整理的图才加比例尺，不给明显变形的示意图配假比例尺 |
| 图例 | 所有设色、线型和符号的含义 | 显示符号样本与中文说明；图上使用的特殊符号必须能在图例中查到 |
| 地势与地貌 | 平原、丘陵、山地、高原、盆地及重要海岸形态 | 连续区域设色，加必要地貌注记；不能靠相同山纹铺满陆地 |
| 水系 | 主要河流、湖泊、河口及必要支流 | 表现源头、汇流、流向、出海或内流终点；自然河与人工渠分开 |
| 政区 | 国家及本图要求的行政层级 | 总图画国界；大陆主图画国界和全部二级界。边线不得被底画或文字遮到无法追踪 |
| 聚落 | 国都、二级治所及重要港口 | 符号有层次，聚落落在可居住的土地上；城名与区名分别标注 |
| 地名 | 现行统一名称 | 正文、数据、地图与索引一致；较大的山系、平原、海域也必须有名称 |
| 说明 | 版次、制作依据及必要阅读限制 | 放图边，不遮盖主体；注明示意性，不用精度说明代替实际核查 |

经纬网和大量高程点并非本书每图必需。全世界坐标尚未编定时，不能用一套看似精确的经纬线制造已测绘的印象。小插图、阴影和装饰边框也不能挤占必备要素。

## 三、图种与信息取舍

### 1. 大洲总图

显示三大陆的相对方位、29国疆界、重要海域、主要山系和大河；标国都与少量跨海主港。使读者看出衡岑远离另两陆，而乌弥尔与萨阑隔海紧密往来。国家采用边线与名称区分，底色优先表达自然地势。

二级行政区、普通治所、基层村坊及各支流不在总图逐一铺开。远航路线采用少量虚线，附航程和候风说明，不把航线画成海上国界。

### 2. 三张大陆主图

同时表达地形与现行政区。主要山系、分水岭、平原、盆地、大湖、河口及全部二级区均须能辨认。重点山口、海港、粮田区和宗教自治地方可以少量补标。

国家名称大于地区名称，地形名称与行政名称采用不同颜色和排法。没有必要将所有三级区和全部史事塞入主图；拥挤的港岛、三角洲和峡谷城邦用局部放大图解释。

### 3. 自然地理与历史补图

当主图不能清楚解释气候、岛群成因或文明形成时，增加小幅配图。气候图用独立图例，历史图有独立年代和势力范围图例。自然地势、现代国界和某次战争的势力范围不能用同一种色块互相替代。

## 四、地形设色

地势以由低到高的浅绿、黄绿、淡黄、赭色、棕色、灰白分层，水面用蓝色。以下为本书统一用色，不是照搬国标色号。

| 对象 | 基本颜色 | 补充表达 |
|---|---|---|
| 海面 | 淡蓝至中蓝 | 沿岸浅水带与较深海面有别，不绘任意密集漩涡 |
| 河湖 | 清楚的蓝色 | 内流湖、季节湖及人工水道用不同线型或注记 |
| 低平原、三角洲 | 浅绿 | 河汊、湿地和海岸低地保持连续；必要时补淹没区纹理 |
| 河阶、低台地 | 黄绿或浅黄 | 与低平原有过渡，河谷切入时应能看见高差 |
| 丘陵、低山 | 淡赭 | 起伏不画成尖锐雪峰，谷地留出可识读空间 |
| 中高山地 | 棕色 | 表现连贯山脊和支谷，鞍部、峡口与主要分水岭有别 |
| 高原 | 高地色阶上的宽广面 | 高原不能只画成密集山峰，边缘陡坎与内部盆地要区分 |
| 雪岭、冰雪 | 灰白 | 只用于符合纬度、海拔与坡向条件的高处，不给每座岛加雪帽 |

分层设色主要说明地势，绿色不自动表示森林。森林、草地、旱地和湿地需另加稀疏纹理或专题小图。高处不一定干，低处不一定湿；不能由地形颜色直接代替气候设定。

未编定具体高程的区域使用“低平地—台地—丘陵—山地—高地”的定性图例。只有确有高程设定的区域才标米数；不得给装饰性山纹配上虚构测量值。

## 五、水系与地貌的规范画法

1. 河流从高地向低地汇流。支流通常向下游汇入，河口和特殊分流河段可以分汊；不能把普通干流一路画成不断分开的树枝。
2. 主要分水岭两侧的河流属于不同水系。穿山河道须有峡谷或继承河道的地理说明；人工跨岭通道另画，不能默认为大河能任意越岭。
3. 盆地分为有出口和内流两类。有出口盆地标河口或峡口；内流盆地标终端湖、盐地或季节湿地，不能一面称内流、一面另画无说明的出海大河。
4. 大湖须交代主要入流和出流。多出口湖仅用于已经设定的低平地形，不因底画好看就随意多开出口。
5. 三角洲位于河流入海或入湖处，表达沉积低地与分汊水道。不得让主三角洲、治所和全部粮田整体漂到远海大岛上。
6. 冲积扇在山口展开，主沟与分流方向向低地；河阶沿谷地排列，不在没有来水条件的山顶画大面积灌田。
7. 喀斯特、沼泽、沙地、盐地、陡崖等重要地貌用约定纹理及文字补充。地下水出口与地表河段分别表示，不把洞泉画成无来源的完整大河。
8. 先使主干水系及山地结构清楚，再取舍小支流和纹理。低平河谷应留白，不能被山纹填满。

## 六、海岸与岛屿

每个主要岛群须有成因、地势、淡水与居民利用的说明。附岛可以按同一地质类型合述，不为几百个小岛逐一虚构地质事件。

| 类型 | 应出现的图形特征 | 须避免的问题 |
|---|---|---|
| 大陆架残余岛 | 与邻近大陆的山脉或岩层方向相联系，中央低山或丘陵、岸湾和小平原相间 | 岛岛都有独立尖峰，所有岸段都是陡崖 |
| 海侵形成的岛链 | 淹没谷地、曲折水道与近岸残丘，较大的岛可能有内部河谷 | 岛屿等距排成整齐珠串，却无地形延续关系 |
| 火山岛 | 山体与侵蚀谷地相容，年轻与老岛地势有差别，可有局部陡岸 | 每岛都是完美火山锥、圆环或中心深坑 |
| 沉积岛与沙洲 | 低平、狭长或受潮流改造，浅水与岸滩联系清楚 | 在低平沙洲上画雪山、深切谷和大量永久大河 |
| 珊瑚岛与礁 | 位于合适的暖浅海，礁坪、潟湖和低地形态可辨 | 把寒海或高大基岩岛都解释为珊瑚形成 |

大岛可以拥有山地、丘陵、河谷和平原；小岛通常只有短沟、季节水或有限地下淡水。沿岸至少区分河口低岸、沙嘴、湾岸与基岩岬角，不能统一画成高台断崖。

原图中不合理的地形须重绘。成因说明应解释地理关系，不能成为保留错图的理由。海上国属按文字与区划核对，不能因为绘图程序需要填满岛屿就任意指派给内陆平原区。

## 七、政区与其他边线

| 线型 | 本书表示方式 | 使用范围 |
|---|---|---|
| 国家边界 | 清晰深紫红色点划线，必要时加窄浅色衬线 | 洲图与大陆图共用同一套国境 |
| 二级行政界 | 较细灰色短划线 | 大陆主图显示全部271区，不压过水系 |
| 重点三级行政界 | 更细的灰色点线 | 原则上只在局部图显示 |
| 宗教自治辖界 | 普通行政边线旁加紫色注记或小符号 | 表示权限限定的自治，不自动升为国界 |
| 历史势力范围 | 有年代的淡色晕带或斜线区 | 只在历史图使用，与现行边界分开 |
| 争议界段 | 另用明确的争议线型并解释双方主张 | 只有正文已有争议的地方才画 |
| 商路、驿路、航线 | 分别用细棕线、细灰线和蓝色虚线 | 均列图例，不与行政界共用线型 |

相邻两地共用同一条界线。图上要看得出国界和二级界的差别，不能仅靠颜色的一点细微变化。自然资源使用权、季节牧路和宗庙私产不是国家主权线，必要时另作专题说明。

## 八、聚落与注记

国都用较醒目的双圆符号，二级治所用普通圆点，重要海港加小港口符号。图例注明符号代表身份而非城市实际面积。城镇沿可居住河阶、山口、岸湾或台地落位；码头可以接水，整座城不能落在外海或高峰上。

国家用较大宋体或同类正文字体，适度疏排；地名在对应地域内居中，并沿辖境长轴安排。国名不要机械放在国都旁边，也不要所有国家一律水平长排。正式全称过长时，图内使用统一简称，右侧名录列全称。

二级区名用较小黑灰字体，山系和高原用棕色疏排，河流、湖泊、海域用蓝色。河名顺河道，山名顺山脉；通名不能因缩字而丢失“河、湖、湾、领、府”等必要区别。

文字不得盖住河口、峡口、城市符号和重要界段。拥挤地区用短引线或局部放大图；极小辖区可在主图用区号，但索引必须列名，不能让大片大陆只剩代码。

## 九、地理与历史的对应

大陆主图应让人直接辨认各文明起步时依赖的地理条件。具体事件用少量编号配表，详论留在正文，避免给全部地图贴满说明框。

- 衡岑：会稽水籍社会对应东部冲积平原、湖群和汇流地；巴文明对应盆地粮田、矿丘、炭林与山口；罗勒文明对应西岸港湾及有限陆地腹地。祖山是山系中的一处祭祀节点，不能覆盖三文明全部源地。
- 乌弥尔：瓜凉对应井泉、冬草、盐路与谷田；芦赫对应浅湖、河阶、鱼田转换和河口；大元溪对应支渠、洲田与跨境水网。霄安和七斗的岸港联系还须在洲图上可见。
- 萨阑：卡兹帕对应高原、盆地与谷牧交换；摩揭始罗对应灌渠河谷及契界；化玻对应水轮、矿丘和炭林；鹿野对应林坡、河田、湖社与牧带。跨岸文明的港口与驿路单独识别。

洪水与改道应能找到低平地、河槽和受灾地域；战争及盟约应能找到山口、粮路、堰门或港道。地理解释说明限制和机会，同时保留制度选择、贸易及人的行动，不能把所有国家命运写成地形的必然结果。

## 十、制作与验收顺序

先定名称和地理设定表，再画海岸、地势与水系；自然地理通过后叠加政区和聚落，最后排文字、图例和索引。生图输出作为候选底画，不能直接充当已经核对的正式地理资料。

每图逐项验收：

1. 必备要素完整，图例与实际符号相符。
2. 平原、高原、丘陵、盆地和山地有明显区别，岛屿没有重复的无依据地形。
3. 水系与分水岭、湖泊、河口和盆地出口相容。
4. 洲图与大陆图方位一致，主要航路与文字说明相容。
5. 国家、二级区和治所逐项对应正文；附岛没有被错误分给仅存在于大陆的三角洲或粮田区。
6. 文明起步所依赖的地貌可辨，关键历史事件有可定位的自然背景。
7. 正常阅读尺寸下主信息清楚，文字、底色和线型互不混淆。
8. 最新图、图层数据、名称索引及正文引用同步；旧版单独保存。

每次修改留下图册核查记录，分别记已发现的问题、修订措施和仍属设定假说的地理解释。数学精度只检查会影响读图的基本关系；不为完善投影、曲线算法或坐标体系拖延世界观的表达。

## 十一、归纳与评价

本图册以自然地理为底、政治区划为线、历史解释为配文。读者首先看见山河、平原和海岸，再辨认国家与地方；同一套颜色和符号贯穿四张主图。图形与文字相互校正，无法解释的地形通过修改解决。
