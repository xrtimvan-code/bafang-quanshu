# 第四版制图制作说明

本目录保存可复用的编绘程序、地形设计和修订前行政栅格。修订前栅格仅作轮廓及辖区来源，现行名称和行政资料以同级目录的三陆图层数据及名称注册表为准。

在本目录用装有 NumPy、Pillow 的 Python 运行 `绘制图册.py`，再用装有 sharp 的 Node.js 运行 `渲染图册.cjs`。sharp 如不在默认模块路径，设置当前进程 `SHARP_MODULE` 为其模块目录。程序不下载依赖、不调用生图接口、不修改 Git 历史。

地形采用编辑确定的山脊、台地、低地、河湖和岛群成因，生成连续设色。相对地势值是绘图等级，不是实测海拔；河流线与地貌带根据正文人工配合，不能用于水文模拟或推算坡降。

海岸与辖区由基础栅格提取平滑线，保留国别和现行区码；剔除衡岑底图右缘的细条伪陆地，纠正乌弥尔三组离岸辖境的元数据。旧版海岛归属错误的订正不构成世界观内的新战争或领土转让。小岛图示有取舍，不是完整海岛普查。

旧版图片及书稿保存在图册旧版目录。新版正文图片按相对路径引用，Obsidian打开书籍根目录即可读取。
