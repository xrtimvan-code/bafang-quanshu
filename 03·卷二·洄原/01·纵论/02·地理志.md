## 一、陆岸、水系与气候

西北的黑岚山弧阻挡西海湿风，北原成为草地、旱地和盐盆交错地。中部槐梁分水岭较低，却把北向的凉水、向西南入湖的芦河与向东南奔流的元溪分开。东部镜门岸多短河、海湾与离岸岛，南缘云雨来自暖海。岚衡在西北远海，通常须绕过外沙和南海风带再转向；不存在跨大陆陆桥。

北部寒温大陆气候，冬寒夏暖、雨量波动；中部温带季风与湖区湿润气候，农业依赖季节洪水；南部暖湿季风气候，低地稻作而台地仍种旱粮；西南背风丘陵有夏干冬雨的小区，东岸多雾和风暴。洄原按四个宏观气候带编定，与岚衡三类气候的区域结构有别。海拔变化产生雪地、林地与干谷，不各算一个宏观带。

凉水源于黑岚东坡，流过乌陇和鹿泉，注入宸渠北部内陆湖，旱年部分末渠断流。芦河源于槐梁西侧，入赫湖后分延浦、盐汊两大出流，分别穿过芦桓和索弥入西南海；元溪源于槐梁东坡，北堰、合流诸支汇成主河，经荻文东泽入南镜门海。旧朝“通三水”以转运渠和陆驿衔接三个自然水系。

## 二、十一大地理单元

| 单元 | 内部主要地貌 | 核心分布与意义 |
|---|---|---|
| 黑岚山弧 | 黑岚林谷、乌陇盐台、西口雪岭 | 阿勒温西缘、瓜陵西部；山口掌盐路，林牧界常发生用地纠纷 |
| 五泉北原 | 青鬃草原、塔日高坪、鹿泉灌谷 | 瓜陵与阿勒温；冬草比夏草更决定牧群归属 |
| 宸渠扇地 | 锁河渠首、麦台台地、柳闸扇面、南圩末梢 | 宸渠；上游开闸不等于下游有水，渗漏与蒸发必须计入 |
| 槐梁分水岭 | 北堰峡口、安越林岭、东辕缓丘 | 中部边界带；矿、纸材和驿道集中 |
| 赫湖盆地 | 芦泽浅湾、赫都湖台、沃岸冲积地 | 芦桓；湖面涨退影响鱼权和田界 |
| 芦河下游 | 延浦河阶、长桥泛滥地、盐汊潮汊 | 芦桓与索弥；河床迁移使一张地契可能失去所指土地 |
| 西南丘湾 | 石萄丘陵、绿汀洼地、燧湾岸崖 | 卡雷及索弥南缘；葡萄、染料、石材与海港 |
| 元溪多汊平原 | 青畦水网、合流洲田、蒲湾芦荡 | 元溪、百契北部；渠堤联动，国家边界不能阻断水务 |
| 南桑台地 | 桑陌缓台、谷风旱地、澜田河阶 | 百契与荻文西部；棉桑、麦稻和移民新村 |
| 镜门陆岸 | 青门海湾、联津双港、广济盐岸、东泽三角洲 | 景廷、西宸、荻文；水深条件形成大小港差别 |
| 北斗岸岛 | 长潮岸台、星沙浅礁、雾舟深水岛、双灯岬 | 北斗；浅礁捕鱼与深水远航对应不同政治利益 |

主要单元是地理区域，123个行政区则是政治边界；一国可以跨几个单元。宸渠东南锁河山口与元溪北堰沿槐梁西支岭直接相接，山口只容季节粮队，为季节陆路。槐梁地形与国家边界并不完全重合：景廷望川与瓜陵东辕之间有缓丘通道，元溪东索与西宸安越也隔谷相接。

## 三、海距与陆路

镜门海最窄岸段约二百四十公里；两岸常规可靠港口航路约三百至八百五十公里，联津到燧岬宸海首港约六百五十公里，双灯到西斗主要北港约八百五十公里；各港路程按实际航线登记，与海峡最短岸距分别使用。季风稳定时前者可三至五日抵达，逆风或检疫使航程拖到半月。岚衡港到洄原最近可行远洋航段约二千四百至三千公里，绕岛补给线路可能超过四千五百公里；一年中常有数月不值得冒险。

衡帐至渠宁陆路约七百公里，渠宁至合流约八百五十公里，赫都至索弥顺河约六百公里，合流至联津约一千公里，景京至联津海岸官道约五百二十公里。步行平地日二十至三十公里，载货牛车十至二十，驿递更换马匹可八十至一百二十，但不适用于整支商队。雨季桥断，纸面上的“十日路”会变成二十日。

## 四、国界形成与跨境资源

瓜陵与阿勒温北界沿两处冬草分水脊，中段以旧盐路界桩衔接，南段允许共同放牧；宸渠与瓜陵以凉水旧堤和东辕丘线分界，取水权另由条约规定。芦桓与索弥在下游沿旧河槽划界，635年洪水后的新河不自动成为国界。卡雷北界跨赫湖浅湾，湖中不存在封闭鱼群的“国籍”。

元溪与百契沿社田契界形成曲折边线，四处共享闸口；百契与荻文有条宽约二十公里的混合佃田带，归籍看居民所在村，租税按田块所在国。景廷与西宸南屏—旧仓边界借旧省界而来，两处景廷宗庙田在西宸境内，作为私有或宗庙产权依法纳税，主权仍归所在地国家。北斗长潮岸盟西南沿短河旧岸堤直接接景廷青门省，是北斗唯一与大陆邻国相接的陆境；其余港岛不因隔海相望就有陆地国界。北斗的近岸岛与景廷青门相望，海上以共同航标和捕鱼季约管理，不把深海画成密闭领土格子。

### 海岸与岛群的图册表达

洄原北岸由伸海台地、切入的湾口和不连续岸坡组成；西南丘湾具有长岬与避风湾，东部河口分汊侵入海岸。北斗主港岛与星沙、双灯、雾舟诸岛大小不一，主岛内部也有山地和河谷，具有不同面积、岸形和地形层次。长潮是接景廷的大陆岸带，与离岸岛区分开。此次图册纠正旧版过于紧凑的轮廓和岛屿绘法，面积、人口及行政名录沿用正文基准。

## 六、归纳评价


北原牧农并营、赫湖鱼田随水位转换、元溪支渠联动和镜门港岸共用交通，分别形成不同的资源协调方式。现行123个二级区沿自然节点与历史契界建立，旧区系保留创约份额。季节气候、道路和水系影响跨境利用，行政分界与资源管理约定在同一空间并行。
